# 接口约定模板

> 用法: 复制到 `.claude/specs/api-conventions.md`，按项目调整。

## 模块间通信

本项目使用 __weak 回调直调（同步），无消息队列。

### __weak 回调（所有跨模块通信）

- **机制**: 发送方定义 `__weak` 空壳函数，接收方提供强符号同名函数。链接器自动接线。
- **函数签名**: `void {Module}_On{Event}(uint16_t param, void *data_ptr)`
- **param**: 轻量数据（键码、索引、布尔值），直接传值
- **data_ptr**: 复杂数据指针，NULL 表示无数据
- **返回值**: 统一 `void`
- **约束**: 回调内不得阻塞、不得嵌套调用耗时逻辑

### 显示装配器 (可选半层)

装配器是 APP 层内的半层模块，不参与业务决策，只做机械转换：

```
业务逻辑 (APP)
  输出: {zone:1, content:"5", effect:BLINK, ...}
        │
        ▼ 调用 Set*() 设置抽象值
显示装配器 (API)
  内部: 缓存抽象值 → 查表 → 组装硬件帧
        │
        ▼ 通过 DRV 注册的回调指针传参
DRV (display)
  收到: 硬件帧 { seg_code[11], led_bits, ... }
  只做: 映射到 IO 引脚，不知道段码来源
```

| 层 | 知道什么 | 不知道什么 |
|----|---------|-----------|
| APP 业务逻辑 | 状态机、路由、功率、定时 | 段码、LED bitmap、IO 引脚 |
| 显示装配器 | 抽象值→段码转换 | 业务决策（为什么选这个模式） |
| DRV | IO 引脚映射、COM 扫描时序 | 段码含义、上层库的存在 |

---

## 函数签名规范
- **返回值**: 全部 `void`（异步通知模型）
- **参数**: `uint16_t param`（轻量数据）+ `void *data_ptr`（复杂数据）
- **数据所有权**: 发送方负责数据生命周期，接收方在回调返回后不得再访问

## 模块依赖规则
```
src/ (main.c)
 ├── app/{业务模块}  ← 纯逻辑，只输出抽象值
 ├── app/api_*       ← 装配器（可选半层）
 ├── drv/{驱动模块}  ← 设备封装
 │   └── hal/{硬件模块} ← 寄存器操作
 ├── proto/{协议模块} ← 编解码
 └── cfg/{配置数据}   ← JSON→C 生成
```
- 禁止循环依赖
- APP → DRV 只有一条合法路径：__weak 回调直调
- HAL 层不知道上层存在
- DRV 层只 include HAL 接口

## 版本兼容
- __weak 回调签名不可变更参数顺序
- 新增回调只加不删（旧回调保留空壳，由链接器自然丢弃）
- 跨模块结构体新增字段只能加在末尾
