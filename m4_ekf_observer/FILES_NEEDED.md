# M4 源文件清单 — 需要你提供的文件

## 存放位置

将所有 M4 工程源文件复制到: `m4_ekf_observer/src/`

建议直接整个工程目录拷过来，避免遗漏。

---

## 必需文件

### 1. MODBUS 从站框架（最优先）
| 文件 | 用途 |
|------|------|
| MODBUS 协议处理 (.c/.h) | 功能码 0x03/0x06/0x10 的请求解析和响应组帧 |
| 寄存器映射表 (.h) | 现有所有寄存器的地址定义，确认 0x1000-0x1015 / 0x2000-0x2003 的布局 |
| 从站初始化 + 主循环 | 在哪里接收 MODBUS 请求、在哪里填充寄存器数据 |

### 2. 主控制循环
| 文件 | 用途 |
|------|------|
| 20ms 定时中断 ISR | 控制周期入口，EKF_Update 调用点 |
| main.c | 系统初始化、主循环结构 |

### 3. 功率控制模块
| 文件 | 用途 |
|------|------|
| PID 控制器 (.c/.h) | 现有功率 PID，需要改造为变增益 |
| 功率计算 (.c/.h) | 从 ADC/HRTIM 计算 P_meas, φ |
| 频率控制 (.c/.h) | HRTIM 频率更新，Δf 输出 |

### 4. 硬件驱动
| 文件 | 用途 |
|------|------|
| HRTIM 驱动 (.c/.h) | 半桥 PWM 生成，频率寄存器操作 |
| ADC 驱动 (.c/.h) | 电压/电流采样，同步采样逻辑 |
| UART 驱动 (.c/.h) | MODBUS 物理层 |

### 5. 系统基础
| 文件 | 用途 |
|------|------|
| 时钟配置 (.c/.h) | MCU 主频、外设时钟 |
| 公共类型定义 (.h) | typedefs, 宏, 项目级常量 |
| Flash/EEPROM 驱动 (.c/.h) | EKF 参数持久化存储（如果有） |
