# v2.3 升级总结

## v2.2 vs v2.3 对比

| 特性 | v2.2 | v2.3 |
|------|------|------|
| **核心框架** | std_module.h | std_module.h (编译开关) |
| **ISR 激活** | 无 | `STD_MODULE_ENABLE_ISR=1` |

| **ISR 数据槽** | 共用 g_input/g_output | ✅ 独立 g_isr_input/g_isr_output |

## 核心变更

### 1. 编译开关 (std_module.h)

```c
#ifndef STD_MODULE_ENABLE_ISR
    #define STD_MODULE_ENABLE_ISR  0
#endif
```

ISR=0: 宏展开与 v2.2 完全一致
ISR=1: MODULE_SKELETON 额外生成 ISR 通路, MODULE_EXPORT 额外生成 GetISR_IO

### 2. 两条独立通路

**主循环通路** (data_switcher.c)
```
Switcher_Run_Slot1() → 按序调用 DoWork → InputCallback → ProcessInput
```

**PendSV 实时通路** (pendsv_switcher.c)
```
ISR_Handler() → Switcher_TriggerPendSV(source)
↓
PendSV_Handler() → 遍历 s_isr_workers[] → ISR_DoWork
    ├─ ISR_InputCallback (PULL 数据)
    ├─ ISR_ProcessInput (三段式)
    └─ ISR_OutputCallback (按需)
```

### 3. 模块注册 (旧 vs 新)

| 旧方案 (已废弃) | 新方案 (v2.3) |
|---|---|
| `std_module_v2.3.h` 单独头文件 | `std_module.h` 统一头文件 + 编译开关 |
| `Switcher_RegisterModule(name, pIn, pOut, pDoWork, pOnISR)` | `Switcher_RegisterISRModule(pISR_DoWork)` |
| 运行时 strcmp 名称查找 | 编译期函数指针数组 |
| `DECLARE_MODULE_OUTPUT` 破坏封装 | `GetISR_IO` 统一入口 |
| 来源路由 (Route_ADC_ISR/Route_Timer_ISR) | 模块通过 g_isr_source 自判断 |

## 使用步骤

### 1. ISR 模块实现

```c
// my_isr_module.c
#define STD_MODULE_ENABLE_ISR  1
#include "std_module.h"
#include "pendsv_switcher.h"

MODULE_SKELETON(MyIsr);

static void Init(void) {
    g_input.para      = &s_in;
    g_output.para     = &s_out;
    g_isr_input.para  = &s_in;
    g_isr_output.para = &s_out;
}

static void ISR_ProcessInput(void) {
    /* 使用 g_isr_source 判断触发来源 */
    switch (g_isr_source) {
        case ISR_SOURCE_ADC:    /* ADC 数据快速处理 */ break;
        case ISR_SOURCE_TIMER:  /* 定时事件 */ break;
    }
}
static void ProcessInput(void) { }  /* 主循环处理 (可选) */

MODULE_EXPORT(MyIsr);
```

### 2. ISR 触发

```c
// isr_triggers.c
#define STD_MODULE_ENABLE_ISR  1
#include "std_module.h"
#include "pendsv_switcher.h"

void ADC_IRQHandler(void) {
    /* 清中断标志 */
    Switcher_TriggerPendSV(ISR_SOURCE_ADC);  // PendSV 触发
}
```

### 3. 系统初始化

```c
// main_init.c
#define STD_MODULE_ENABLE_ISR  1
#include "std_module.h"
#include "data_switcher.h"
#include "pendsv_switcher.h"

void System_Init(void) {
    /* PendSV 通路初始化 */
    Switcher_PendSV_Init();
    Para_Grp_t *pIn, *pOut;
    void (*pISR_DoWork)(void);
    MyIsr_GetISR_IO(&pIn, &pOut, &pISR_DoWork);
    Switcher_RegisterISRModule(pISR_DoWork);

    /* 主循环通路初始化 (v2.2 方式不变) */
    Switcher_Init();
}
```

## PendSV Handler 流程

```
ISR_Handler()
    ↓
Switcher_TriggerPendSV(source)
    ├─ g_isr_source = source
    ├─ g_isr_pending = 1
    └─ SCB->ICSR |= PENDSVSET
    ↓
PendSV_Handler()  [所有 ISR 退出后执行]
    ├─ g_isr_pending == 0? 返回
    ├─ g_isr_pending = 0
    └─ 遍历 s_isr_workers[]
        └─ 调用每个 ISR_DoWork()
```

**硬件特性**:
- PendSV 优先级最低，在所有 ISR 完成后执行
- 同级中断不嵌套，无需软件锁
- 多次触发 PendSV 累积为一次

## 迁移指南 (v2.2 → v2.3)

1. **替换 std_module.h** — v2.3 版本，ISR 默认不启用，现有模块零修改
2. **新 ISR 模块** — 文件顶部加 `#define STD_MODULE_ENABLE_ISR 1`
3. **PendSV 通路** — 复制 `pendsv_switcher.c/h` 到项目 core/
4. **ISR 改写** — ISR 只做两件事：清标志 + `Switcher_TriggerPendSV()`
5. **初始化** — 新增 `Switcher_PendSV_Init()` + `Switcher_RegisterISRModule()`
