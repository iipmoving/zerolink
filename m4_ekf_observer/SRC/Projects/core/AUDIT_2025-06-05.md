## 变更概览

本次重构目标: app_power.c 不再直接调用 APP_ADC 函数，全部通过 `__weak` 回调和 struct 指针通信。

| 文件 | 变更类型 | 关键改动 |
|------|----------|----------|
| `APP_ADC.H` | +struct | 新增 `AdcRawInput` (52B, owner) |
| `APP_ADC.C` | +填充/+STRONG | 新增 `g_adc_raw` 填充逻辑 + `Adc_GetRawInputPtr` STRONG; 删除 T12a/T34a __weak 桩 |
| `app_power.h` | +struct/+声明 | 新增 `Power_RawInput_IN_t`, `Power_AwdDntr_IN_t` consumer 副本; 导出 `APP_PPG_SetIcVcOk` |
| `app_power.c` | +__weak/-耦合 | 新增 `Adc_GetRawInputPtr` __weak 桩; `PPGgetAdcValue` 改为 struct 指针; 删除 `AdcValueFun` 调用; 删除 `T12aCallBack` 空壳 |
| `app_task.c` | +前置调用 | `Task_TimeChip0` 新增 `AdcValueFun()` → `APP_PPG_SetIcVcOk()` |
| `interface_map.h` | +注册 | @STRUCT S6/S7 + __weak Pair I |

### Chain 2: getADCinputValue → Adc_GetRawInputPtr + AdcRawInput (数据通道迁移)

**Before** (`app_power.c` → `PPGgetAdcValue(ch)`):
```c
CurrentValue16  = getADCinputValue(AdcGroupT1A+ch);    // 直接调用×5
VoltageValue    = getADCinputValue(AdcGroupVoltage)>>4;
powerPhase      = getADCinputValue(AdcGroupPhase1+ch);
s_limit_Qsum    = getADCinputValue(AdcGroupCeilQ1+ch);
powerAdcFactTxa = APP_ADC_GetPowerTxa(PotCh1+ch);       // 直接调用
```
其中 `getADCinputValue(ch)` 返回 `AdcFunRam.inputValue[ch]`

**After** (`app_power.c` → `PPGgetAdcValue(ch)`):
```c
const Power_RawInput_IN_t* raw =
    (const Power_RawInput_IN_t*)Adc_GetRawInputPtr();   // __weak 取址一次
if (!raw) return;
CurrentValue16  = raw->txa_current[ch];                  // struct 下标
VoltageValue    = raw->voltage>>4;
powerPhase      = raw->phase[ch];
s_limit_Qsum    = raw->ceil_q[ch];
powerAdcFactTxa = Adc_GetPowerTxa(PotCh1+ch);           // 已是 __weak
```

**数据桥接** (`APP_ADC.C` → `AdcValueFun()` 末尾):
```c
if (xReturn) {
```
