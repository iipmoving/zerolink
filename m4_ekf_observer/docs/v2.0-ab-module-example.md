# v2.0 AB 模块范例 — Data Switcher 中间层架构

> **目的**: 展示 v2.0 方法论的核心模式：Producer → Switcher → Consumer

---

## 整体架构

```
┌───────────────────────────────────────────────────────────────┐
│                    调度槽 Slot1 (~10ms)                        │
├───────────────────────────────────────────────────────────────┤
│                                                               │
│   [Producer A]              [Switcher]               [Consumer B] │
│   ┌─────────┐              ┌─────────┐               ┌─────────┐│
│   │ A_DoWork│ ──执行─────→│检测bit1 │←───读取─────→│         ││
│   │ 产生数据│              │(新数据?)│               │         ││
│   │置位bit1 │              └────┬────┘               │         ││
│   └─────────┘                   │ YES                │         ││
│                                 ↓                    │         ││
│                           ┌─────────┐                │         ││
│                           │B_OnInput│ ←──回调────────│         ││
│                           │(pA_Out) │   结构体传参    │         ││
│                           └────┬────┘                │         ││
│                                │清bit1               │         ││
│                                ↓                     │ B_DoWork││
│                           ┌─────────┐                │ 消费数据││
│                           │路由完成 │ ──触发───────→  │         ││
│                           └─────────┘                └─────────┘│
│                                                               │
└───────────────────────────────────────────────────────────────┘
```

## 一、Producer A 模块

### 1.1 app/module_a.h

```c
/**
 * @file    module_a.h
 * @brief   模块 A - 数据生产者
 * @layer   app
 * @deps    core/, proto/, <std>
 */

#ifndef MODULE_A_H
//#define MODULE_A_H   /* L0 compiler block — 禁止跨模块 include */

/* === INTERFACE STRUCTS (OWNER) ================================== */
/* @STRUCT ModuleA_Output  owner=module_a  suffix=OUT */
typedef struct {
    uint8_t  status;        /* offset=0, size=1, bit0=已构造, bit1=新数据 */
    uint8_t  res[3];        /* offset=1, size=3, 32位对齐 */
    uint32_t sensor_value;  /* offset=4, size=4, 传感器读数 */
    uint16_t timestamp;     /* offset=8, size=2, 时间戳 */
} ModuleA_Output_t;          /* sizeof=12 */


/* ---- public interface ---- */

void ModuleA_Run(void);


#endif /* MODULE_A_H */
```

### 1.2 include/module_a_io.h

```c
/**
 * @file    module_a_io.h
 * @brief   Module A Data Switcher IO interface
 * @layer   app (Data Switcher IO)
 *
 * 本文件定义 Module A 对外暴露的输出接口.
 * 仅 data_switcher.c 可用全路径 include 本文件.
 */

#ifndef MODULE_A_IO_H
#define MODULE_A_IO_H       /* ← 保留: _io.h 是公开接口 */

#include <stdint.h>

#pragma pack(4)

typedef struct {
    uint8_t  status;        /* bit0=已构造, bit1=新数据就绪 */
    uint8_t  res[3];        /* 32位对齐 */
    uint32_t sensor_value;  /* 传感器读数 */
    uint16_t timestamp;     /* 时间戳 */
} ModuleA_Output_t;          /* sizeof=12 */

#pragma pack()

/* ---- public interface ---- */

void ModuleA_GetIO(ModuleA_Output_t **ppOut);
void ModuleA_DoWork(void);


#endif /* MODULE_A_IO_H */
```

### 1.3 app/module_a.c

```c
/**
 * @file    module_a.c
 * @brief   模块 A - 数据生产者实现
 * @layer   app
 */

#include "module_a.h"

/* === OUTPUT BUFFER === */
static ModuleA_Output_t s_out;

/* === 内部状态 === */
static uint16_t s_counter = 0;

/* ====== ModuleA_Run (三段式) ====== */

/* === 构造函数 (懒惰初始化) === */
static void ModuleA_Construct(void)
{
    s_out.status = 0x01;     /* bit0=已构造 */
    s_counter = 0;
}

/* ====== ModuleA_Run (三段式) ====== */

void ModuleA_Run(void)
{
    static uint8_t _constructed = 0;
    if (!_constructed) { 
        _constructed = 1; 
        ModuleA_Construct();  /* 首次进入时调用构造函数 */
    }

    /* ====== INPUT PHASE ====== */
    /* 生产者模块通常无外部输入 */

    /* ====== COMPUTE PHASE ====== */
    s_counter++;
    s_out.sensor_value = s_counter * 10;  /* 模拟传感器数据 */
    s_out.timestamp = s_counter;

    /* ====== OUTPUT PHASE ====== */
    s_out.status |= 0x02;     /* bit1=新数据就绪 */
}

/* === IO Interface === */
void ModuleA_GetIO(ModuleA_Output_t **ppOut)
{
    *ppOut = &s_out;
}

void ModuleA_DoWork(void)
{
    s_out.status &= ~0x02;    /* 每帧先清就绪标志 */
    ModuleA_Run();
}
```

## 二、Consumer B 模块

### 2.1 app/module_b.h

```c
/**
 * @file    module_b.h
 * @brief   模块 B - 数据消费者
 * @layer   app
 * @deps    core/, proto/, <std>
 */

#ifndef MODULE_B_H
//#define MODULE_B_H   /* L0 compiler block — 禁止跨模块 include */

/* === INTERFACE STRUCTS (OWNER) ================================== */
/* @STRUCT ModuleB_Output  owner=module_b  suffix=OUT */
typedef struct {
    uint8_t  status;        /* offset=0, size=1 */
    uint8_t  res[3];        /* offset=1, size=3 */
    uint32_t processed;     /* offset=4, size=4, 处理后结果 */
} ModuleB_Output_t;          /* sizeof=8 */


/* ---- public interface ---- */

void ModuleB_Run(void);


#endif /* MODULE_B_H */
```

### 2.2 app/module_b.c

```c
/**
 * @file    module_b.c
 * @brief   模块 B - 数据消费者实现
 * @layer   app
 */

#include "module_b.h"
#include "../include/module_a_io.h"  /* 仅在消费者内部使用，不对外暴露 */

/* === OUTPUT BUFFER === */
static ModuleB_Output_t s_out;

/* === 输入回调声明 (Switcher 会覆盖) === */
__weak void ModuleB_OnInput(ModuleA_Output_t *pInput) 
{ (void)pInput; }

/* === 构造函数 (懒惰初始化) === */
static void ModuleB_Construct(void)
{
    s_out.status = 0x01;     /* bit0=已构造 */
    s_out.processed = 0;
}

/* ====== ModuleB_Run (三段式) ====== */

void ModuleB_Run(void)
{
    static uint8_t _constructed = 0;
    if (!_constructed) { 
        _constructed = 1; 
        ModuleB_Construct();  /* 首次进入时调用构造函数 */
    }

    /* ====== INPUT PHASE ====== */
    ModuleA_Output_t input;
    ModuleB_OnInput(&input);  /* 从 Switcher 获取输入 */

    /* ====== COMPUTE PHASE ====== */
    s_out.processed = input.sensor_value * 2;  /* 处理数据 */

    /* ====== OUTPUT PHASE ====== */
    s_out.status |= 0x02;     /* bit1=新数据就绪 */
}

/* === IO Interface === */
void ModuleB_GetIO(ModuleB_Output_t **ppOut)
{
    *ppOut = &s_out;
}

void ModuleB_DoWork(void)
{
    s_out.status &= ~0x02;
    ModuleB_Run();
}
```

## 三、中间层 Switcher

### 3.1 core/data_switcher.c

```c
/**
 * @file    data_switcher.c
 * @brief   v2.0 Data Switcher — 结构化数据路由中间层
 * @layer   core
 */

#include "data_switcher.h"
#include "../include/module_a_io.h"
#include "../include/module_b_io.h"

/* === 内部指针缓存 === */
static ModuleA_Output_t *pA;
static ModuleB_Output_t *pB;

/* === 初始化 === */
void Switcher_Init(void)
{
    ModuleA_GetIO(&pA);
    ModuleB_GetIO(&pB);

    pA->status = 0x01;
    pB->status = 0x01;
}

/* === Slot1 调度入口 (~10ms) === */
void Switcher_Run_Slot1(void)
{
    /* Step 1: 执行 Producer A */
    ModuleA_DoWork();

    /* Step 2: 检测 A 的新数据 → 路由到 B */
    if (pA->status & 0x02) {           /* A 有新数据? */
        ModuleB_OnInput(pA);           /* 直接传结构体指针 */
        pA->status &= ~0x02;           /* Switcher 清标志 */
    }

    /* Step 3: 执行 Consumer B */
    ModuleB_DoWork();
}

/* === __weak 空壳 (app_task 调用) === */
__weak void Switcher_Run_Slot1(void) {}
__weak void Switcher_Init(void) {}
```

### 3.2 core/interface_map.h 注册

```c
/* === v2.0 Switcher Pairs === */

/* Pair AB: ModuleA → ModuleB (Switcher 路由) */
 * 发送方: data_switcher.c  WEAK void ModuleB_OnInput(ModuleA_Output_t *pInput) {}
 * 接收方: module_b.c  void ModuleB_OnInput(ModuleA_Output_t *pInput)
 * v2.0: Switcher 检测 status bit1 → 回调(结构体直接传参) → 清标志
 */

/* Pair Task→Switcher: 调度入口 */
 * 发送方: app_task.c  WEAK void Switcher_Run_Slot1(void) {}
 * 接收方: data_switcher.c  void Switcher_Run_Slot1(void)
 */
```

## 四、关键设计要点

### 4.1 Status Bit 协议

| Bit | 含义 | 设置方 | 清除方 |
|-----|------|--------|--------|
| bit0 | 已构造 | 模块自身 | 永不清除 |
| bit1 | 新数据就绪 | Producer | **Switcher** |

### 4.2 文件权限规则

| 文件类型 | Include Guard | 允许 include 的文件 |
|---------|--------------|-------------------|
| `module_a.h` | `//#define` | 仅 `module_a.c` |
| `module_a_io.h` | `#define` | `data_switcher.c` + `module_a.c` |
| `module_b.h` | `//#define` | 仅 `module_b.c` |

### 4.3 三段式结构

```c
void Module_Run(void) {
    // INIT: static 标志检查 → 调用构造函数
    
    // INPUT: 集中获取外部数据
    //        调用 _OnInput() 回调
    
    // COMPUTE: 纯计算，无外部调用
    //          状态机、算法、数据变换
    
    // OUTPUT: 集中输出结果
    //         设置 status bit1
}
```

### 4.4 构造函数模式（标准范式）

**构造函数是 v2.0 方法论的标准范式**，所有模块必须遵循此模式。构造函数采用**懒惰初始化**策略，上电时中间层通过清零初始化标志位统一触发所有模块的构造函数，无需手动逐个初始化。

```c
/* === 构造函数 (标准范式) === */
static void Module_Construct(void)
{
    s_out.status = 0x01;     /* bit0=已构造 */
    // 初始化内部状态变量
    // 配置参数设置
    // 硬件资源初始化（如果需要）
}

/* === 运行入口 === */
void Module_Run(void)
{
    static uint8_t _constructed = 0;  /* 初始化标志位 */
    if (!_constructed) {              /* 首次进入时 */
        _constructed = 1; 
        Module_Construct();           /* 自动调用构造函数 */
    }
    // ... 三段式主体 ...
}
```

**构造函数规则**:
| 规则 | 说明 |
|------|------|
| **命名** | `Module_Construct()`，必须是 `static` 函数 |
| **调用时机** | 模块首次进入 `Module_Run()` 时自动调用 |
| **职责** | 初始化内部状态、设置初始参数、配置硬件资源 |
| **禁止** | 不调用外部模块、不依赖未初始化的资源 |
| **标志位** | 设置 `status bit0` 表示已构造 |

**优势**:
| 优势 | 说明 |
|------|------|
| **零手动初始化** | `main()` 不需要调用任何 `Module_Init()` |
| **上电统一触发** | Switcher 清零所有模块的初始化标志位，首次调度时自动构造 |
| **按需初始化** | 只在模块真正被使用时才初始化 |
| **统一入口** | 所有初始化逻辑集中在一个地方 |
| **热重启友好** | 重置 `_constructed` 标志即可重新初始化 |

### 4.5 上电初始化流程

v2.0 方法论的核心优势之一是**自动初始化机制**：

```
上电复位
    ↓
Switcher_Init() 被调用
    ↓
Switcher 清零所有模块的初始化标志位 (_constructed = 0)
    ↓
调度开始，Switcher_Run_SlotX() 执行
    ↓
各模块的 Module_Run() 首次被调用
    ↓
检测到 _constructed == 0
    ↓
自动调用 Module_Construct()
    ↓
设置 _constructed = 1
    ↓
设置 status bit0 = 1 (已构造)
    ↓
进入正常三段式执行
```

**关键设计**:
```c
// Switcher 初始化时绑定所有模块指针
void Switcher_Init(void)
{
    ModuleA_GetIO(&pA);
    ModuleB_GetIO(&pB);
    // ... 其他模块
    
    // 清零初始化标志（通过 status bit0 间接判断）
    // 模块首次 Run 时检测到 bit0 == 0 → 触发构造函数
}
```

**对比传统方式**:

| 方式 | 初始化调用 | 复杂度 | 维护成本 |
|------|-----------|--------|---------|
| **传统方式** | `main()` 中逐个调用 `ModuleA_Init()`, `ModuleB_Init()`, ... | O(n) | 新增模块需修改 main |
| **v2.0 方式** | 无需显式调用，自动触发 | O(1) | 新增模块无需修改任何代码 |

**结论**: 构造函数作为标准范式，实现了**真正的零初始化代码**——新增模块无需在任何地方注册初始化调用，Switcher 会自动完成所有模块的构造。

## 五、执行流程

```
1. app_task 调用 Switcher_Run_Slot1()
       ↓
2. Switcher 调用 ModuleA_DoWork()
       ↓
3. ModuleA_Run():
   - INPUT: 空（生产者）
   - COMPUTE: 生成 sensor_value
   - OUTPUT: 置位 bit1
       ↓
4. Switcher 检测 pA->status & 0x02 == true
       ↓
5. Switcher 调用 ModuleB_OnInput(pA)
       ↓
6. Switcher 清零 pA->status bit1
       ↓
7. Switcher 调用 ModuleB_DoWork()
       ↓
8. ModuleB_Run():
   - INPUT: 从 _OnInput 获取数据
   - COMPUTE: sensor_value * 2
   - OUTPUT: 置位 bit1
```
