## 1. 测量能力边界

硬件只采集了两路信号，所有计算都受这个约束：

```
┌──────────────┐
│   ADC 采样    │
├──────────────┤
│ I  (整流后)  │ → f_res / I_RMS / I_peak / 谷值 → φ(估算)
│ Vdc (母线)   │ → Vdc_mean / 纹波 / V_fund(估算)
│ ✗ V_res      │ → 缺！无法直接算 |Z| / S / Q / 精确相位
│ HRTIM CMP    │ → f_sw / D% / 死区 / 模式(精确)
└──────────────┘
```

## 3. 逐文件审查

### 3.1 `calibration.m` — ✅ 正确

ADC 标定链路完整无误：

```
V_actual = ADC × Vref / 4096 / 分压比
         = ADC × 3.3 / 4096 / (6.2k / (810k + 6.2k))
         = ADC × 0.10606 V/cnt    ✓

I_actual = ADC × Vref / 4096 / 分压比 × CT变比 / 取样电阻
         = ADC × 3.3 / 4096 / (330/(10k+330)) × 2000/2000
         = ADC × 0.02523 A/cnt    ✓
```

验证点：
| 通道 | ADC | 物理值 | 预期 | 结论 |
|------|-----|--------|------|------|
| Vdc | 2850 | 302V | ~311V(220V整流) | ✅ |
| I | 795 | 20.0A | 2kW级IH合理 | ✅ |

### 3.2 `load_data.m` — ❌ PERIOD 计算 BUG

**问题代码**（约第94行）：
```matlab
CNT_range = CNT_max - CNT_min;  % CNT 绕回时出错！
```

**错误后果**：
```
CSV中 CNT: 25304 → 25768 → 120(绕回)
CNT_max = 25768, CNT_min = 120
CNT_range = 25768 - 120 = 25648    ❌
正确 PERIOD = 26032               ✓
```

**影响链及误差量化**：

| 参量 | 错误值 | 正确值 | 误差 |
|------|--------|--------|------|
| PERIOD counts | 25648 | 26032 | -384 (-1.5%) |
| f_sw | 29.85 kHz | 29.50 kHz | +350 Hz (+1.2%) |
| T_hrtim | 33.40 μs | 33.90 μs | -0.5 μs |
| DT2 (下关→上开) | 1.948 μs | 2.344 μs | **-0.4 μs (-17%)** |
| D_U | 36.4% | 36.1% | 接近 |
| φ | +59.7° | 待重算 | 间接影响 |

**修复方法**：检测 CNT 负跳变，用绕回前值 + 绕回后值 + 步长推算真实 PERIOD。

| 项目 | 结论 |

### 3.4 `calc_waveform.m` — ✅ 正确

**谷值法检测整流电流周期**是唯一正确的方法：
- 每两个谷值 = 谐振半周期
- f_res = 1 / (2 × T_half)

CSV 验证：谷值间隔约 17μs → f_res ≈ 1/(2×17μs) ≈ 29.4kHz，与 f_sw 接近（合理）。

### 3.5 `calc_phase.m` — ⚠️ 方法正确，φ 符号待核实

**原理**：
```matlab
φ = (t_valley - t_UON) / T_sw × 360°
```

电流谷值（整流后）对应原电流过零点，CMP_UON 对应半桥输出电压基波过零点。  
**概念 ✅ 正确。**

**手动验算**：
```
t_valley ≈ 24μs, t_UON = 0 (CNT=768)
T_sw ≈ 33.9μs
φ = 24/33.9 × 360° = 255°

归一化到[-180,180]：255° - 360° = -105° (感性)
代码只保留 abs(φ)≤90 → -105°被过滤掉
输出 φ = +59.7° → 可能是另一组谷值的数据
```

**❌ 问题**：象限归一化逻辑可能过于激进，感性负载 φ=-105° 正确但被排除了。  
**建议**：放宽过滤范围到 [-180, 180]，或根据 f_sw 与 f_res 的关系判断感/容性。

### 3.6 `calc_power.m` — ⚠️ 估算合理，V_fund 方程有前提

**基波法公式正确**：
```
P = V_fund_RMS × I_RMS × cos(φ)
V_fund_RMS = Vdc × √2/π × sin(πD)
```

验证 D=36.4% 时：sin(π×0.364) = sin(65.5°) = 0.910 ✅

**但隐含前提**：负载电流连续（CCM）。若工作在 DCM（轻载），V_fund 关系式失真，P 误差增大。

### 3.7 `calc_impedance.m` — ⚠️ 最大估算误差来源

```
|Z|_est = V_fund_RMS / I_RMS
R_est = P / I_RMS²
```

**核心问题**：`V_fund_RMS` 是半桥输出电压基波，不是谐振电压。实际 |Z| = V_res / I，谐振回路会放大电压，所以 `|Z|_est` 系统性偏低。

### 3.8 `calc_rlc.m` — ✅ 思路正确，依赖已知 C

```matlab
V_C_peak = I_peak / (ω × C)      % 频域电容电压
L = (Vdc/2 + V_C_peak) / (I_peak × ω)  % KVL 半桥中点参考
```

**手动验算**：
```
Vdc=302V, Vdc/2=151V
I_peak=20.04A, ω=2π×29500=185354 rad/s
V_C_peak = 20.04/(185354×0.9e-6) = 120.1V
L = (151+120.1)/(20.04×185354) = 73.0μH
MATLAB 输出 L=71.78μH → 差异 1.7%（来自 f_sw 误差）
```

**依赖风险**：C=0.9μF 是已知值，若实际有 ±10% 偏差，L 也会偏离 ±10%。

## 5. 三个需要核实的问题

### 问题1：φ 的符号和数值

手动算得 φ ≈ -105°（感性），但输出 +59.7°。  
`calc_phase.m` 的过滤条件 `abs(phi_deg) <= 90` 可能排除了正确的感性相位。  
**建议**：先修复 PERIOD BUG，再对比 φ 值，放宽过滤或根据 f_sw/f_res 关系定符号。

### 问题2：V_fund_RMS 在 calc_impedance 中的误差量级

```matlab
V_fund_RMS = Vdc × √2/π × sin(πD)
```

半桥输出方波的基波 ≈ 0.45×Vdc，但谐振回路在 f_sw 处的阻抗可能放大或缩小这个电压。  
以实测数据为例：Vdc≈302V → V_fund_RMS≈136V，但实际谐振电压未知。  
**如果有 V_res 通道，可以量化这个误差。**

### 问题3：C=0.9μF 的敏感性

`calc_rlc.m` 的 L 计算直接依赖 C：

| C 实际值 | 算得 L | 偏差 |
|---------|--------|------|
| 0.81 μF (-10%) | 79.0 μH | +10% |
| 0.90 μF (标称) | 71.8 μH | 基准 |
| 0.99 μF (+10%) | 65.4 μH | -9% |

**建议**：确认谐振电容的实际容值（用电桥测量），或标注为标称值带容差。

## 5b. 推导链完整性验证 (修正审计前提后)

V_res 不能测只能推，那 `calc_rlc.m` 就是**核心推导引擎**。验证其 KVL 方程：

### KVL 封闭解推导

在电流过零点 (i=0, 整流后谷值)：
- **i = 0** → V_R = i × R = 0 ← 电阻项消掉
- **V_C 在负峰** = -V_C_peak = -I_peak / (ωC) ← 电容电压滞后电流 90°
- **V_L 在峰值** = L × ω × I_peak ← 电感电压超前电流 90°，过零处斜率最大
- **V_sw = +Vdc/2** ← 过零时刻上管已开通，半桥中点 = Vdc/2

KVL：Vdc/2 = L·ω·I_peak + (-V_C_peak)  
→ **L = (Vdc/2 + V_C_peak) / (I_peak · ω)** ← **闭合解，不需要 V_res**

### 四参量推全链

| 步骤 | 输入 | 输出 | 公式 | 依赖测量 |
|------|------|------|------|---------|
| 1 | Vdc, I_peak, f_sw, **C(已知)** | L | (Vdc/2 + I_peak/ωC) / (I_peak·ω) | I, Vdc, C |
| 2 | L, C | f_res | 1 / (2π√LC) | — |
| 3 | φ, f_sw, f_res | Q | tan(φ) / (f_sw/f_res - f_res/f_sw) | φ(谷值法) |
| 4 | ω₀, L, Q | R | ω₀L / Q | — |
| 5 | I_RMS, R | P | I_RMS² × R | I |

**所有 5 个电参数 (L, f_res, Q, R, P) 全部从 I + Vdc + C 推导，不需要 V_res** ✅

### 关于 dI/dt

`calc_rlc.m` 计算了 `di_dt`（第 48-49 行）但**未参与任何计算**，仅放入输出结构体备查。注释称"dI/dt 法"有误导性——实际用的是**频域 V_C_peak 法**，不是时域 dI/dt 法。建议删除无用代码或改为实际使用时域斜率。

### calc_impedance.m 的地位

`calc_impedance.m` 的 `|Z|_est = V_fund_RMS / I_RMS` 是**备用的估算方法**。有了 `calc_rlc.m` 的封闭解后，RLC 参数应以 `calc_rlc.m` 为准，`calc_impedance.m` 仅做交叉验证。

## 7. 最终结论

1. **参数齐全度**：时序/时域参数 ✅ 完整精确。功率/阻抗参数 ⚠️ 可估算但缺 V_res 无法精确。

2. **计算正确性**：物理模型和公式 ✅ 正确，与手动验算一致。主要误差来自 PERIOD BUG（已定位）和 V_fund 代替 V_res 的根本性近似。

3. **MATLAB 输出非虚构**：审查验证了 8 个参数的手动验算，大部分与输出一致，偏差可归因于已定位的 BUG。

4. **最大改进点**：增加谐振电压 V_res 采样通道，可直接计算 |Z|、S、Q，并与现有估算方法交叉验证。
