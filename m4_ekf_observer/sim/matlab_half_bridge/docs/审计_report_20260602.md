## 一、参数齐全性分析（V_res 不可测约束下）

### 1.1 理论上可从 I(t) + Vdc + CNT/CMP 推导的参数

| 参数 | 符号 | 推导路径 | 约束下是否可算 |
|------|--------|----------|----------------|
| 峰值电流 | I_peak | max(I) | ✅ 直接 |
| 有效值电流 | I_RMS | rms(I) | ✅ 直接 |
| 开关频率 | f_sw | CNT周期 | ✅ 直接 |
| 占空比 | D_U | (CO-CU)/period | ✅ 直接 |
| 谐振频率 | f_res | 谷值间隔 = T_res/2 | ✅ 推导 |
| 相位差 | φ | 谷值相对CMP_UON延迟 | ⚠️ 近似 |
| 阻抗模 | \|Z\| | V_fund_RMS / I_RMS | ✅ 推导 |
| 等效电阻 | R | \|Z\|cosφ 或 P/I_RMS² | ✅ 推导 |
| 电抗 | X | \|Z\|sinφ | ✅ 推导 |
| 电感 | L | (X + 1/ωC)/ω | ✅ 推导 |
| Q值 | Q | tanφ/(f_sw/f_res - f_res/f_sw) | ✅ 推导 |
| 有功功率 | P | V_fund×I_RMS×cosφ | ✅ 推导 |
| 谐振电容电压 | V_C(t) | (1/C)∫I_actual(t)dt | ⚠️ 需重构符号 |

### 1.2 参数齐全性结论

**在 V_res 不可测的约束下，所有关键电性能参数均可通过 I(t) + Vdc + CNT/CMP 推导得到。**

缺失的不是参数，而是**推导精度**：
- φ 的精度受限于"谷值相对CMP_UON延迟"的近似定义（非严格V_fund过零）
- V_C_peak 如果用 `I_peak/(ωC)` 近似，会引入系统误差
- 如果能从 I(t) 数值积分推导 V_C(t)，L 的计算精度可显著提升

### 2.2 `load_data.m` — ⚠️ 有绕回修正，但实现有轻微近似

**第114-123行已有绕回修正**：
```matlab
wrap_fix = find(diff(CNT) < 0, 1);
if ~isempty(wrap_fix)
    cnt_before = CNT(wrap_fix);
    cnt_after  = CNT(wrap_fix + 1);
    CNT_range = cnt_before + round(avg_dcnt) - cnt_after;
```

**问题**：`round(avg_dcnt)` 假设CNT增量固定，但HRTIM是768MHz计数，增量未必是整数。**误差约±1 count**，对26032 counts的周期影响约0.004%，可忽略。

**结论**：方向正确，精度可接受。✅

### 2.3 `calc_timing.m` — ⚠️ 控制模式判别逻辑有误

**第102行**：
```matlab
if D_std < 2 && mean(D_U_pct) > 45
    ctrl_mode = 'FM';
```

**问题**：固定占空比36.4%时，`mean(D_U_pct)=36.4 < 45`，会被误判为PWM模式。

**建议**：改成基于 `mode_50pct`（占空比是否接近50%）来判断，或直接删除FM/PWM判别（你的场景是固定占空比，不属于FM或PWM）。

### 2.4 `calc_waveform.m` — ✅ 正确

- 谷值检测法适用于整流后电流 ✅
- `I_peak_est × 0.15` 阈值过滤浅谷 ✅
- f_res 从谷值间隔计算：`f_res = 1/(2×T_half)` ✅
- I_RMS 计算正确 ✅

### 2.5 `calc_phase.m` — ⚠️ φ定义不严格

**方法**：
```matlab
phi_deg = (dist_cnt / (T_sw_us / t_pcnt)) * 360;
```

**问题**：φ 定义为"电流谷值相对CMP_UON的延迟角"，不是严格的"电流相对电压基波过零的相位差"。

**影响**：
- 对 ZVS 判断（φ>0 即感性）方向正确 ✅
- 但 cosφ 数值会有误差，影响 P 的计算精度 ⚠️

**建议**：明确注释 φ 的物理定义，避免后续使用者误解。

### 2.6 `calc_power.m` — ✅ 公式正确

**基波法**：
```matlab
V_fund_rms = Vdc_mean * (sqrt(2) / pi) * max(sin(pi*D_U), 0.1);
P = V_fund_rms * I_RMS * cos_phi;
```

**审计**：
- `V_fund_rms = Vdc × √2/π × sin(πD)` ✅ 公式正确
- `P = V_fund × I_RMS × cosφ` ✅ 公式正确
- 方法A（直流侧法）保留对照，方法B（基波法）作为主要输出 ✅

### 2.7 `calc_rlc.m` — ❌ V_C_peak 公式不严谨，KVL公式物理意义不清晰

**第56行**：
```matlab
V_C_peak = I_peak / (omega * C_FARAD);
```

**问题**：`I_peak/(ωC)` 是正弦稳态下电容电压幅值的近似，但你的电流不是理想正弦（含谐波）。**这是近似，不是精确推导**。

**第62行KVL公式**：
```matlab
L_val = (Vdc/2 + V_C_peak) / (I_peak * omega);
```

**问题**：这个公式的物理意义不清晰。在哪个时刻列KVL？上管开通时电流过零，此时 V_C ≈ -V_C_peak，V_L = L×dI/dt 最大（不是0）。**公式需要澄清**。

**正确的相量法**（TEST_REPORT.md 里写了，但代码未实现）：
```matlab
V_fund_rms = Vdc * sqrt(2)/pi * sin(pi*D);
Z_mag = V_fund_rms / I_RMS;
X = Z_mag * sin(phi);          % 电抗
L = (X + 1/(omega*C)) / omega; % 因为 X = ωL - 1/(ωC)
```

### 2.8 `calc_impedance.m` — ❌ V_fund_rms 公式错误

**第28行**：
```matlab
V_fund_rms = Vdc_mean / pi;  % ← 错误！
```

**正确公式**：
```matlab
V_fund_rms = Vdc_mean * (sqrt(2)/pi) * sin(pi*D_U);
```

**误差**：当 D=50% 时，代码输出 V_fund_rms = Vdc/π ≈ 0.318Vdc，正确值 = Vdc×√2/π ≈ 0.451Vdc，**误差约41%**。

**注**：calc_impedance.m 标注了"估算"，且 main.m 里 impedance 结果似乎不是主要输出。但公式错误仍需修正。

## 四、V_res 不可测约束下的最优推导链建议

### 4.1 当前推导链（有近似）

```
I(t)整流 → 谷值检测 → φ ≈ 延迟角
                        → V_C_peak ≈ I_peak/(ωC)  （近似）
                        → L ≈ (Vdc/2 + V_C_peak)/(I_peak·ω)  （需澄清）
```

### 4.2 建议推导链（更严谨）

**方法A：相量法（推荐，不需要V_res测量）**

```matlab
% 1. 基波电压有效值（从Vdc和D计算，不需要V_res测量）
V_fund_rms = Vdc * sqrt(2)/pi * sin(pi*D_U);

% 2. 阻抗模
Z_mag = V_fund_rms / I_RMS;

% 3. 电抗和电阻
X = Z_mag * sin(phi);   % 工科相位定义：感性X>0
R = Z_mag * cos(phi);

% 4. 电感（串联RLC模型）
% X = ωL - 1/(ωC)
L = (X + 1/(omega*C)) / omega;

% 5. Q值
Q = X / R;  % 或 tan(phi)/(f_sw/f_res - f_res/f_sw)
```

**方法B：V_C(t) 数值积分法（如果有需要高精度L的场景）**

```matlab
% 1. 从谷值点重构 I_actual(t) 的符号
%    谷值 = I_actual 过零点，相邻半周期符号相反
I_actual = zeros(size(I_rect));
I_actual(valley(1):valley(2)) = +I_rect(valley(1):valley(2));  % 假设
I_actual(valley(2):valley(3)) = -I_rect(valley(2):valley(3));  % 交替

% 2. V_C(t) = (1/C) ∫ I_actual(t) dt
V_C = cumtrapz(t, I_actual) / C;

% 3. V_L(t) = V_sw(t) - V_C(t) - I_actual(t)*R
%    V_sw(t) 从 CMP 边沿重建（上管开通=Vdc，下管开通=0）

% 4. L = V_L_peak / (dI/dt_peak)
```
