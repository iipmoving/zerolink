## 一、参量运算过程清单

### 1.1 原始数据 → 物理量

```
ADC 原始值          标定常数           物理量
─────────────────────────────────────────────────
I_adc (0-4095)  →  I_SCALE = 3.3/4096/(330/10330) = 0.02522  →  I (A)
Vdc_adc          →  VDC_SCALE = V_SCALE = 131.65               →  Vdc (V)
CNT (0-65535)    →  t_per_cnt_us = avg_dt_us / avg_dcnt        →  t (μs)
CMP[1]=CU        →  上管开通点 HRTIM 值
CMP[2]=CO        →  上管关断点 HRTIM 值
CMP[3]=LON       →  下管开通点
CMP[4]=LOFF      →  周期终点 (= period)
```

### 1.2 f_sw 开关频率

```
dCNT_pos = diff(CNT_clean) > 0
avg_dcnt = mean(dCNT_pos)
CNT_range = 检测绕回边界修正
Tu_us = CNT_range × t_per_cnt_us       # 开关周期 (μs)
f_sw_kHz = 1000 / Tu_us                # 开关频率 (kHz)
```

### 1.3 D_U 占空比

```
D_U = (CO - CU) × t_per_cnt_us / Tu_us   # 上管占空比 (0-1)
```

### 1.4 I_rms 谐振电流有效值

```
I_clean = I_adc[best_seg] × I_SCALE      # 最长单调段
I_rms = sqrt(mean(I_clean²))             # RMS (全帧)
```

### 1.5 φ 相位角

```
方法: 谷值检测 + 上升沿过零检测, 取中位数
cpc = Tu / t_per_cnt_us                  # 每周期 CNT 数
1) 找谷值: I[i-1]>I[i] && I[i]<I[i+1] && I[i]<Ipk×0.15
2) 抛物线插值: cnt_interp = CNT[vi] + frac
3) φ = (cnt_interp - CU) / cpc × 360°    # 相对开通点的相位
4) 筛选: φ ∈ [8°, 85°]
5) 最终: φ = median(所有检测到的有效φ)
```

### 1.6 L 电感量

```
ω = 2π × f_sw
V1 = (√2/π) × Vdc_mean × sin(π × D_U)   # 基波电压有效值
Z = V1 / I_rms                           # 阻抗模
X = Z × sin(φ)                           # 感抗
L = (1/(ωC) + X) / ω × 1e6               # 电感 (μH), C=0.94μF
```

### 1.7 L 修正 (I_rms B-H 补偿)

```
同频段线性拟合: L = a + b × I_rms
L_corr = L_raw - b × (I_rms - I_ref)     # 修正到频段中值 I_rms
```

### 1.8 P_W 有功功率 (上下管分离)

```
I_zero = median(I_adc)                    # 零电流 ADC 偏置
I_act = (I_adc - I_zero) × I_SCALE       # 有符号电流 (A)

上管有功段: [valley_up, CO]
  Σ_up = Σ I_act[i] × Vdc[i]             # 逐点积分
  插值: 最后一点 × frac = (CO-CNT[i])/(CNT[i+1]-CNT[i])

下管有功段: [valley_down, period_cnt]
  Σ_down = Σ I_act[i] × Vdc[i]           # 对称检测

P_W = (Σ_up + Σ_down) / N_total           # 非对称
P_W = 2 × Σ_up / N_total                  # 对称 (D≈50%)
```

### 1.9 Kalman 滤波 (标量, L 状态)

```
预测: x_pred = x_est, P_pred = P + Q
创新: innov = L_meas - x_pred
增益: K = P_pred / (P_pred + R)           # R = R0 / (I_rms/10)
更新: x_est = x_pred + K × innov
      P = (1-K) × P_pred
突变检测: |innov| > 3.5σ_run              # 50点滑动窗
```

## 三、L 参量数据流图

```
CSV原始数据 (9列)
  │
  ├─→ calc_one_frame()

  │     ├─ rms(I_clean) → I_RMS_A
```
