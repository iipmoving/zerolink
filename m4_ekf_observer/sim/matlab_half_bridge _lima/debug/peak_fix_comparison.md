# 峰值检测修正 — 前后对比报告

## 修正内容

I_peak 检测窗口从 `[CMP_UON, v_up]` 改为 `[v_up, CMP_UOFF]`

| 旧窗口 | 新窗口 |
|--------|--------|
| 起点 = CMP_UON 开通点 | 起点 = **v_up 第一谷值（过零点）** |
| 终点 = v_up 谷值 | 终点 = **CMP_UOFF 关断点** |
| 包含上一周期关断噪音 ✅ | 排除关断噪音 ✅ |
| 只能取到假峰值 ❌ | 取到真谐振峰值 ✅ |

## 说明

I_peak 下降 7.1% 直接传导到 L 计算：

```
L = (Vdc/2 + I_peak/ωC) / (I_peak × ω)
```

I_peak 在分子分母都有，L 上升幅度接近 I_peak 下降幅度（~7%），但具体值需在 MATLAB 中重新跑 `export_golden_batch.m` 才能精确对比。
