# modules/API

## 职责

- 提供对 HAL 的“二次封装”（更贴近该项目的命名、资源编号与数据流）
- 对外暴露统一的 `API_*` 接口，业务层基本只与 API 交互
- 承接 `Users/rx32g4xx_it.c` 转发出来的中断回调（通过同名强符号覆盖弱符号）

## 关键接口速读

### GPIO（API_gpio.h）

- 通过枚举 `PIN_MAX` 定义“业务可见”的逻辑 IO 索引（Debug/Zero/PWM/TXA/风扇/I2C 等）[API_gpio.h](file:///D:/OBSIDIAN/MOVING%20IH/%E4%BD%8E%E8%80%A6%E5%90%88%E7%A8%8B%E5%BA%8F%E6%9E%B6%E6%9E%84/m4_ekf_observer/src/RX32G410_FW_HAL_V1.3N/Projects/API/inc/API_gpio.h#L11-L85)
- 初始化与读写入口：`API_GPIO_PORT_INIT()` / `API_GPIO_WritePin()` / `API_GPIO_ReadPin()` [API_gpio.h](file:///D:/OBSIDIAN/MOVING%20IH/%E4%BD%8E%E8%80%A6%E5%90%88%E7%A8%8B%E5%BA%8F%E6%9E%B6%E6%9E%84/m4_ekf_observer/src/RX32G410_FW_HAL_V1.3N/Projects/API/inc/API_gpio.h#L104-L111)

### DMA（API_DMA.H）

- 以 `API_DMA_CH_ENUM` 统一抽象 DMA 通道（M2M/电流 ADC/UART RxTx/HRTIM 等）[API_DMA.H](file:///D:/OBSIDIAN/MOVING%20IH/%E4%BD%8E%E8%80%A6%E5%90%88%E7%A8%8B%E5%BA%8F%E6%9E%B6%E6%9E%84/m4_ekf_observer/src/RX32G410_FW_HAL_V1.3N/Projects/API/inc/API_DMA.H#L34-L53)
- 常用入口：`API_DMA_Init()` / `API_DMA_START()` / `API_DMA_GetDmaCndtr()` [API_DMA.H](file:///D:/OBSIDIAN/MOVING%20IH/%E4%BD%8E%E8%80%A6%E5%90%88%E7%A8%8B%E5%BA%8F%E6%9E%B6%E6%9E%84/m4_ekf_observer/src/RX32G410_FW_HAL_V1.3N/Projects/API/inc/API_DMA.H#L82-L90)

### ADC（API_adc.h）

- 该模块核心是“ADC + DMA 缓冲 + 中断/EOC 控制 + M2M 拷贝”
- 常用入口：`API_ADC_Init()`，以及一系列 `*_ENABLE_IT_EOC()` / `*_DISABLE_IT_EOC()` [API_adc.h](file:///D:/OBSIDIAN/MOVING%20IH/%E4%BD%8E%E8%80%A6%E5%90%88%E7%A8%8B%E5%BA%8F%E6%9E%B6%E6%9E%84/m4_ekf_observer/src/RX32G410_FW_HAL_V1.3N/Projects/API/inc/API_adc.h#L119-L133)
- 软件触发：`portPendvSet()` / `portPendvClear()`（与 `PendSV_Handler()` 路径联动）[API_adc.h](file:///D:/OBSIDIAN/MOVING%20IH/%E4%BD%8E%E8%80%A6%E5%90%88%E7%A8%8B%E5%BA%8F%E6%9E%B6%E6%9E%84/m4_ekf_observer/src/RX32G410_FW_HAL_V1.3N/Projects/API/inc/API_adc.h#L219-L220)
