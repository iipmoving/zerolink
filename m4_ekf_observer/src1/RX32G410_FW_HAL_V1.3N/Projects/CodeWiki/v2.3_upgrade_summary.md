## v2.3 核心特性

### 1. 两条通路

**主循环通路**
```
Switcher_Run_Slot1() → 按序调用 DoWork → InputCallback → ProcessInput
```

**PendSV 实时通路**
```
ISR_Handler() → Switcher_TriggerPendSV(source)
↓
PendSV_Handler() → 加锁 → Switcher_Run_ISR_Slot() → 解锁 + 累积检查
↓
ISRWORK_DoWork() → CollectInput() → ProcessInput()
```

### 2. 加锁机制

```c
volatile uint8_t g_pendsv_busy;   /* PendSV 处理锁 */
volatile uint8_t g_isr_pending;   /* ISR 请求标志 */
volatile uint8_t g_isr_source;    /* ISR 来源标识 */
```

### 3. 辅助宏

```c
DECLARE_MODULE_OUTPUT(ModuleA);

COLLECT_FROM_MODULE(dst_ptr, ModuleA, A_Data_t);
```

##  PendSV Handler 流程

```
ISR_Handler()
    ↓
Switcher_TriggerPendSV(source)
    ↓
PendSV_Handler()
    ↓
    ├─ 检查 g_isr_pending (无请求? 返回)
    ├─ g_isr_pending = 0 (清标志)
    ├─ Switcher_Run_ISR_Slot()
    │   └─ 按来源路由
    │       ├─ Switcher_Route_ADC_ISR()
    │       ├─ Switcher_Route_Timer_ISR()
    │       └─ ...
    └─ 退出中断 (自动开中断，如有新请求会再次触发)
```

**硬件保护**:
- PendSV 作为中断本身就有硬件保护
- 进入中断时自动关中断（同优先级）
- 退出时自动开中断
- 不需要额外的软件锁

## 升级迁移指南

### 从 v2.2 升级到 v2.3

1. **替换头文件引用**
   ```c
   // #include "core/std_module.h"  // v2.2
   #include "core/std_module_v2.3.h"  // v2.3
   ```

2. **添加 PendSV 初始化**
   ```c
   Switcher_PendSV_Init();
   Switcher_RegisterModule("ModuleName", ...);
   ```

3. **ISR 改为触发 PendSV
   ```c
   void ADC_IRQHandler(void) {
       Switcher_TriggerPendSV(ISR_SOURCE_ADC);
   }
   ```

4. **创建 ISRWORK 模块
   - 使用 `MODULE_SKELETON(ISRWORK)`
   - 实现 `CollectInput()` + `ProcessInput()`
