# v2.3 双模块管道连接指南 — Calculator → ElecParams 完整示例

> **核心思想**：生产者输出 LINK 与消费者输入 LINK 布局相同，中间层用 `(void*)` 指针直穿，零拷贝。
> **对称命名**：生产者 OUTPUT 成员名 = `{Consumer}_params`，消费者 INPUT 成员名 = `{Producer}_params`

---

## 一、三层结构速览

每个数据管道分三层定义，从内到外：

```
第一层: MODULE_xxx_PARAMS(Producer, Consumer)  → 纯数据字段
第二层: MODULE_xxx_LINK(Producer, Consumer)    → 管道 (status + params[])
    第三层: MODULE_INPUT(Consumer)                  → 输入聚合 (*指针)
            MODULE_OUTPUT(Producer)                 → 输出聚合 (实例)

**LINK 命名规则**：
- 类型名 `MODULE_INPUT_LINK(Calculator, ElecParams)` 展开为 `Calculator_to_ElecParams_Input_Link`——**来源模块名 `Calculator` 和目标模块名 `ElecParams` 已嵌入类型名**，类型系统自文档。
- 数据数组统一叫 `params`，不用 `cycles`、`data` 等自定义名字。
```

## 二、生产者定义 output_io.h（以 Calculator 为例）

```c
// calculator_io.h — Calculator 模块 IO 定义
#include "std_module.h"

/* ====== 第一层：数据参数 ====== */
typedef struct {
    int32_t  field1;            // 示意字段，实际按需定义
    int32_t  field2;
    uint8_t  valid;
    uint8_t  res[3];
} MODULE_OUTPUT_PARAMS(Calculator, ElecParams);  // → Calculator_to_ElecParams_Output_Params

/* ====== 第二层：输出管道 ====== */
typedef struct {
    uint8_t  status;
    uint8_t  max_count;
    uint8_t  count;
    uint8_t  res[1];
    MODULE_OUTPUT_PARAMS(Calculator, ElecParams) params[POT_MAX];
} MODULE_OUTPUT_LINK(Calculator, ElecParams);    // → Calculator_to_ElecParams_Output_Link
//   ↑ 类型名已嵌入来源 Calculator → 目标 ElecParams

/* 本生产者还可能输出给其他消费者 */
typedef struct {
    int32_t resonant_current;
    int32_t phase_angle;
} MODULE_OUTPUT_PARAMS(Calculator, PowerBase);

typedef struct {
    uint8_t  status;
    uint8_t  max_count;
    uint8_t  res[2];
    MODULE_OUTPUT_PARAMS(Calculator, PowerBase) params[CALC_POTMAX];
} MODULE_OUTPUT_LINK(Calculator, PowerBase);

/* ====== 第三层：输出聚合 ====== */
typedef struct Calculator_Output {
    MODULE_OUTPUT_LINK(Calculator, ElecParams)  ElecParams_params;  // ← 以消费者命名
    MODULE_OUTPUT_LINK(Calculator, PowerBase)   power_direct;       // ← 次管道保留具名
} MODULE_OUTPUT(Calculator);                    // → Calculator_Output

/* 导出声明 */
MODULE_IO_H(Calculator);
```

## 三、消费者定义 input_io.h（以 ElecParams 为例）

```c
// elec_params_io.h — ElecParams 模块 IO 定义
#include "std_module.h"

/* ====== 第一层：数据参数（布局与生产者 OUTPUT_PARAMS 一致） ====== */
typedef struct {
    int32_t  field1;            // 字段顺序/类型/大小与 OUTPUT_PARAMS 完全相同
    int32_t  field2;
    uint8_t  valid;
    uint8_t  res[3];
} MODULE_INPUT_PARAMS(Calculator, ElecParams);   // → Calculator_to_ElecParams_Input_Params

/* ====== 第二层：输入管道（布局与生产者 OUTPUT_LINK 一致） ====== */
typedef struct {
    uint8_t  status;
    uint8_t  max_count;
    uint8_t  count;
    uint8_t  res[1];
    MODULE_INPUT_PARAMS(Calculator, ElecParams) params[POT_MAX];
} MODULE_INPUT_LINK(Calculator, ElecParams);     // → Calculator_to_ElecParams_Input_Link

/* ====== 第三层：输入聚合 ====== */
typedef struct {
    MODULE_INPUT_LINK(Calculator, ElecParams)* Calculator_params;  // ← 以生产者命名，指针！
} MODULE_INPUT(ElecParams);                      // → ElecParams_Input

/* 本消费者还可能输出给下游 */
typedef struct {
    int32_t result;
    uint8_t valid;
} MODULE_OUTPUT_PARAMS(ElecParams, PowerBase);

typedef struct {
    uint8_t  status;
    uint8_t  event;
    uint8_t  res[2];
    MODULE_OUTPUT_PARAMS(ElecParams, PowerBase) params[ELEC_POTMAX];
} MODULE_OUTPUT_LINK(ElecParams, PowerBase);

typedef struct {
    MODULE_OUTPUT_LINK(ElecParams, PowerBase)  PowerBase_params;  // ← 以消费者命名
} MODULE_OUTPUT(ElecParams);

/* 导出声明 */
MODULE_IO_H(ElecParams);
```

## 四、宏详解

### 4.1 命名宏（展开类型名）

| 宏 | 展开示例 |
|---|---------|
| `MODULE_OUTPUT_PARAMS(Calculator, ElecParams)` | `Calculator_to_ElecParams_Output_Params` |
| `MODULE_INPUT_PARAMS(Calculator, ElecParams)` | `Calculator_to_ElecParams_Input_Params` |
| `MODULE_OUTPUT_LINK(Calculator, ElecParams)` | `Calculator_to_ElecParams_Output_Link` |
| `MODULE_INPUT_LINK(Calculator, ElecParams)` | `Calculator_to_ElecParams_Input_Link` |
| `MODULE_OUTPUT(Calculator)` | `Calculator_Output` |
| `MODULE_INPUT(ElecParams)` | `ElecParams_Input` |
| `MODULE_IO_H(ElecParams)` | 声明 `void ElecParams_GetIO(...)` |

**规则**：`MODULE_xxx_OUTPUT_yyy` 与 `MODULE_xxx_INPUT_yyy` 是一对，布局相同，类型名不同。

### 4.2 连接宏（data_switcher.h）

| 宏 | 用途 | 何时用 |
|---|------|--------|
| `INPUT_CALLBACK(producer, consumer)` | 生成 `consumer##_InputCallback(void)` 函数名 | 声明回调函数壳 |
| `INPUT_GET_SLOT(producer, consumer)` | 指针直穿赋值 `in->producer_params = &out->consumer_params` | 回调体内，零拷贝 |
| `INPUT_LINK_PULL(producer, consumer, link)` | 同 INPUT_GET_SLOT + 回调内检查 ST_NEW + 置 ST_NEW | 需要在回调内完成判断 |
| `INPUT_EDGE_PULL(producer, consumer, link)` | ST_OUT 边沿触发版，自动清除 | ST_OUT 触发场景 |

### 4.3 对称命名规则 — 最关键

```
生产者 OUTPUT 成员名 = 消费者名 + _params
  例: out->ElecParams_params    (MODULE_OUTPUT_LINK(Calculator, ElecParams) 实例)

消费者 INPUT 成员名  = 生产者名 + _params
  例: in->Calculator_params     (MODULE_INPUT_LINK(Calculator, ElecParams)* 指针)
```

连接时的赋值自然就是：
```c
in->Calculator_params = (void*)&out->ElecParams_params;
//  ↑ 生产者名           ↑ 消费者名
// 两句完全对称，数据流向一目了然
```

### 4.4 SLOT 宏（data_switcher.h）

| 宏 | 用途 |
|---|------|
| `SLOT(Calculator)` | 展开为 `SLOT_Calculator`（枚举值） |
| `SLOT_GETIO(Calculator)` | 展开为 `Calculator_GetIO(&s_slot[SLOT_Calculator].pIn, &s_slot[...].pOut, &s_slot[...].pDoWork)` |

## 五、中间层连接（data_switcher）

### 5.1 data_switcher.h — 宏定义

```c
#ifndef DATA_SWITCHER_H
#define DATA_SWITCHER_H

#include "std_module.h"

/* 槽位宏 */
#define SLOT(mod)  SLOT_##mod

#define SLOT_GETIO(mod) \
    mod##_GetIO(&s_slot[SLOT(mod)].pIn, &s_slot[SLOT(mod)].pOut, &s_slot[SLOT(mod)].pDoWork)

/* ===== InputCallback 宏 ===== */

/* 函数壳 */
#define INPUT_CALLBACK(producer, consumer) \
    void consumer##_InputCallback(void)

/* 指针直穿（推荐：检查放 ProcessInput） */
#define INPUT_GET_SLOT(producer, consumer) \
    MODULE_OUTPUT(producer) *out = \
        (MODULE_OUTPUT(producer) *)s_slot[SLOT(producer)].pOut->para; \
    MODULE_INPUT(consumer)   *in  = \
        (MODULE_INPUT(consumer)   *)s_slot[SLOT(consumer)].pIn->para; \
    in->producer##_params = (void*)&out->consumer##_params

/* 管道直穿 + 回调内检查 ST_NEW */
#define INPUT_LINK_PULL(producer, consumer, link_member) \
    do { \
        MODULE_OUTPUT(producer) *__p_out = \
            (MODULE_OUTPUT(producer) *)s_slot[SLOT(producer)].pOut->para; \
        if (__p_out && (__p_out->link_member.status & ST_NEW)) { \
            MODULE_INPUT(consumer) *__p_in = \
                (MODULE_INPUT(consumer) *)s_slot[SLOT(consumer)].pIn->para; \
            if (__p_in) { \
                __p_in->producer##_params = (void*)&__p_out->link_member; \
                s_slot[SLOT(consumer)].pIn->info.status |= ST_NEW; \
            } \
        } \
    } while (0)

/* ST_OUT 边沿触发 */
#define INPUT_EDGE_PULL(producer, consumer, link_member) \
    do { \
        MODULE_OUTPUT(producer) *__p_out = ...; \
        if (__p_out && (__p_out->link_member.status & ST_OUT)) { \
            __p_out->link_member.status &= ~ST_OUT; \
            ... \
        } \
    } while (0)

void Switcher_Init(void);
void Switcher_Run_Slot1(void);
void Switcher_Run_TK(void);

#endif
```

### 5.2 data_switcher.c — 连接实现

```c
#include "std_module.h"
#include "data_switcher.h"
#include "calculator_io.h"     // 生产者的 IO
#include "elec_params_io.h"    // 消费者的 IO

/* 槽位枚举 */
typedef enum {
    SLOT(Calculator) = 0,
    SLOT(ElecParams) = 1,
    SLOT(COUNT)
} SwitcherSlot_t;

static ModuleSlotDef s_slot[SLOT_COUNT];

/* 注册 */
void Switcher_Init(void)
{
    SLOT_GETIO(Calculator);
    SLOT_GETIO(ElecParams);
}

/* ===== InputCallback — 指针直穿 ===== */
INPUT_CALLBACK(Calculator, ElecParams)     // → void ElecParams_InputCallback(void)
{
    INPUT_GET_SLOT(Calculator, ElecParams);
    /* 展开:
     *   Calculator_Output *out = s_slot[SLOT_Calculator].pOut->para;
     *   ElecParams_Input  *in  = s_slot[SLOT_ElecParams].pIn->para;
     *   in->Calculator_params = (void*)&out->ElecParams_params;
     */
}

/* 调度运行 */
void Switcher_Run_TK(void)
{
    s_slot[SLOT_Calculator].pDoWork();    // Calculator 先产出数据
    s_slot[SLOT_ElecParams].pDoWork();    // ElecParams DoWork → InputCallback(直穿) → ProcessInput
}
```

### 5.3 有额外处理逻辑的 InputCallback（不推荐但必要时可用）

```c
INPUT_CALLBACK(Calculator, ElecParams)
{
    /* 用 INPUT_LINK_PULL 可以在回调内做 ST_NEW 判断 */
    INPUT_LINK_PULL(Calculator, ElecParams, ElecParams_params);
}
```

## 六、消费者实现（elec_params.c）

```c
#define STD_MODULE_ENABLE_ISR  0
#include "std_module.h"
#include "elec_params_io.h"
#include <string.h>

/* 数据实例 */
static ElecParams_Input  s_in;
static ElecParams_Output s_out;

MODULE_SKELETON(ElecParams);

static void Init(void)
{
    memset(&s_in,  0, sizeof(s_in));
    memset(&s_out, 0, sizeof(s_out));
    g_input.para  = &s_in;
    g_output.para = &s_out;
}

static void ProcessInput(void)
{
    ElecParams_Input  *in  = (ElecParams_Input  *)g_input.para;
    ElecParams_Output *out = (ElecParams_Output *)g_output.para;

    if (!in->Calculator_params) return;             // 指针还没被赋值
    if (!(in->Calculator_params->status & ST_NEW)) return;
    in->Calculator_params->status &= ~ST_NEW;       // 消费后清除

    /* 读取 in->Calculator_params->params[h].field1 → 计算 → 写入 out */

    out->PowerBase_params.status |= ST_OUT;          // 输出就绪
}

MODULE_EXPORT(ElecParams);
```

## 七、生产者实现（calculator.c）

```c
#define STD_MODULE_ENABLE_ISR  0
#include "std_module.h"
#include "calculator_io.h"
#include <string.h>

static Calculator_Input  s_in;       // Calculator 也有自己的输入（从 ADC 来）
static Calculator_Output s_out;

MODULE_SKELETON(Calculator);

static void Init(void)
{
    memset(&s_in,  0, sizeof(s_in));
    memset(&s_out, 0, sizeof(s_out));
    g_input.para  = &s_in;
    g_output.para = &s_out;
}

static void ProcessInput(void)
{
    Calculator_Output *out = (Calculator_Output *)g_output.para;

    /* 计算... */

    /* 写输出数据 */
    out->ElecParams_params.params[0].field1 = 42;
    out->ElecParams_params.status |= ST_NEW;        // 置 ST_NEW，通知消费者
}

MODULE_EXPORT(Calculator);
```

## 八、使用步骤（六步法）

| 步骤 | 做什么 | 涉及文件 |
|------|--------|----------|
| **① 定数据契约** | 确定生产者和消费者之间的数据结构（字段、类型、大小） | `docs/data-contract.md` |
| **② 生产者定义 OUTPUT** | 在 `producer_io.h` 中定义三层：`OUTPUT_PARAMS` → `OUTPUT_LINK` → `MODULE_OUTPUT`，成员名 `{Consumer}_params` | `calculator_io.h` |
| **③ 消费者定义 INPUT** | 在 `consumer_io.h` 中定义三层：`INPUT_PARAMS` → `INPUT_LINK` → `MODULE_INPUT`，成员名 `{Producer}_params`（指针） | `elec_params_io.h` |
| **④ 中间层连接** | `data_switcher.h` 已有宏；`data_switcher.c` 加 SLOT 枚举 + SLOT_GETIO 注册 + `INPUT_CALLBACK { INPUT_GET_SLOT }` | `data_switcher.h/.c` |
| **⑤ 消费者实现** | `MODULE_SKELETON` + `Init` + `ProcessInput`（三段式）+ `MODULE_EXPORT` | `elec_params.c` |
| **⑥ 生产者实现** | `MODULE_SKELETON` + `Init` + `ProcessInput`（写输出 + 置 ST_NEW）+ `MODULE_EXPORT` | `calculator.c` |

## 九、常见错误

| 错误 | 后果 | 检查方法 |
|------|------|----------|
| INPUT_PARAMS 布局与 OUTPUT_PARAMS 不一致 | 指针直穿后字段偏移错乱 | 逐个字段比对类型/顺序/大小 |
| LINK 内数据数组不叫 `params`（如叫 `cycles`） | 违反统一约定，增加认知负担 | LINK struct 内数据数组必须叫 `params` |
| LINK 补齐字段不用 `res[N]`（如用 `_enable`） | padding 应统一用 `res[N]` 命名 | LINK 内 padding 统一 `uint8_t res[N]` |
| OUTPUT 成员名不是 `{Consumer}_params` | INPUT_GET_SLOT 宏展开后成员名不匹配 | 检查 `out->xxx_params` 命名 |
| INPUT 成员名不是 `{Producer}_params`（指针） | INPUT_GET_SLOT 宏展开 `in->xxx_params` 找不到 | 检查 `in->xxx_params` 命名 |
| OUTPUT_LINK 是实例，INPUT_LINK 是*指针 | 搞反了会导致编译/运行错误 | 检查 `第三层`：OUTPUT 是实例，INPUT 是指针 |
| 在 InputCallback 中修改 status | 通过别名修改了生产者的状态位 | 回调内只做指针赋值，不做 `status |= ST_xx` |
| 先调了消费者 DoWork，后调生产者 DoWork | 消费者读到过时数据 | 确保 `Switcher_Run_TK` 中先生产者后消费者 |

## 十、原始文件勘误

以下错误在整理时已修正：

1. **数据体后多了分号**：`elec_params_io.h` 中 `MODULE_INPUT_PARAMS(Calculator, ElecParams); cycles[ELEC_POTMAX * ELEC_CYCLE_MAX];` → 去掉 `MODULE_INPUT_PARAMS(...)` 后的分号，否则 `cycles` 字段缺少类型。

2. **重复宏定义**：`std_module.h` 中 `#define MODULE_INPUT_LINK` 被定义了两次（第 756 行和第 758 行）。第 758 行是拷贝粘贴错误，应删除。

3. **注释缺少 `/*`**：第 209 行 `================================================================` 前缺少 `/*`，编译器会报语法错误。
