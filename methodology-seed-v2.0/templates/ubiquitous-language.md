## 七、系统分层术语

| 中文 | 英文 | 定位 |
|------|------|------|
| HAL 层 | Hardware Abstraction Layer | 寄存器操作、外设驱动（不知上层存在） |
| DRV 层 | Driver Layer | 设备封装、ISR 衔接（只知 HAL + __weak回调） |
| PROTO 层 | Protocol Layer | 通讯协议编解码 |
| APP 层 | Application Layer | 业务逻辑（只通过 __weak 回调通信） |
| __weak 回调 | Weak Callback | 发送方空壳 + 接收方强符号，链接器自动接线 |
| 装配器 | Assembler | APP 半层：抽象值→硬件值机械转换 |
