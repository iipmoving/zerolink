# 四头电磁炉 Modbus RTU 通信协议规格书 V1.0

> 基于 IH_MoBus版协议_25.12.02_V1.1 整理

---

## 1. 范围

本规格书定义四头商用电磁炉主机（STM32）与从机IH控制板之间的 **Modbus RTU** 通信协议。从机板管理4个炉头，通过 Modbus 站号（5/10/15/20）区分各炉头通道。仅涉及协议层打通，不包含故障码定义及功率分配策略。

---

## 2. 硬件架构

```
+---------------------------------------------------+
|                    主机 (STM32)                      |
|             低耦合架构主控 MCU                      |
+------------------------+--------------------------+
                         | UART (共用母线)
                         |
          +--------------+--------------+
          |     从机 IH 控制板            |
          |   1颗从机管理4个炉头           |
          +--+------+------+------+-----+
             |      |      |      |
          炉头1   炉头2   炉头3   炉头4
         站号5   站号10  站号15  站号20
```

| 项目 | 说明 |
|---|---|
| 主机 MCU | STM32（低耦合架构主控） |
| 从机 | 1颗 IH 控制板，管理4个炉头 |
| 炉头通道站号 | 炉头1=5, 炉头2=10, 炉头3=15, 炉头4=20 |
| 物理层 | UART 直连（共用母线） |
| 协议 | 标准 Modbus RTU |
| 寻址方式 | 通过 Modbus 站号识别不同炉头通道 |

## 3. 通信参数

| 参数   | 值           |
| ---- | ----------- |
| 波特率  | 57600 bps   |
| 数据位  | 8           |
| 奇偶校验 | 无 (N)       |
| 停止位  | 1           |
| 字节格式 | 8N1         |
| 传输模式 | RTU (二进制)   |
| 功能码  | 0x03 读保持寄存器 |
|      | 0x06 写单个寄存器 |
|      | 0x10 写多个寄存器 |
| 通信周期 | 100ms 轮询一次  |
| 字节间隔 | ≤ 1.5 字符时间  |
| 帧间隔  | ≥ 3.5 字符时间  |

### Modbus RTU 帧格式

**读寄存器 (0x03)：**
```
主机发送: [从机地址] [0x03] [起始地址高8] [起始地址低8] [寄存器数高8] [寄存器数低8] [CRC低8] [CRC高8]
从机应答: [从机地址] [0x03] [字节数] [数据高8] [数据低8] ... [CRC低8] [CRC高8]
```

**写单个寄存器 (0x06)：**
```
主机发送: [从机地址] [0x06] [寄存器地址高8] [寄存器地址低8] [数据高8] [数据低8] [CRC低8] [CRC高8]
从机应答: [从机地址] [0x06] [寄存器地址高8] [寄存器地址低8] [数据高8] [数据低8] [CRC低8] [CRC高8]
```

**写多个寄存器 (0x10)：**
```
主机发送: [从机地址] [0x10] [起始地址高8] [起始地址低8] [寄存器数高8] [寄存器数低8] [字节数] [数据...] [CRC低8] [CRC高8]
从机应答: [从机地址] [0x10] [起始地址高8] [起始地址低8] [寄存器数高8] [寄存器数低8] [CRC低8] [CRC高8]
```

## 4. 寄存器映射

寄存器地址 = Modbus 协议地址（即 0x1000 直接作为 Modbus 寄存器地址使用）。每个炉头通道拥有独立的寄存器空间，由 Modbus 站号区分。

### 4.1 只读寄存器 (0x1000 - 0x1020) — 从机上报给主机

| 地址 | 名称 | 说明 | 类型 |
|---|---|---|---|
| 0x1000 | 系统状态 | bit7: 初始化完成 (1=完成，与旧版 bit0 一致) | R |
| 0x1001 | 电压 AD | 母线电压采样值 | R |
| 0x1002 | 电流 AD | 母线电流采样值 | R |
| 0x1003 | IGBT AD | IGBT 温度采样值 | R |
| 0x1004 | 炉面 AD（底部） | 炉面底部温度采样值 | R |
| 0x1005 | 风扇 AD | 风扇电流/转速采样 | R |
| 0x1006 | 顶部 AD（预留） | 炉面顶部温度采样（预留） | R |
| 0x1007 | 实际功率 | 当前实际加热功率 | R |
| 0x1008 | 实际加热 PPG | 当前实际 PPG 值 | R |
| 0x1009 | 功率限制状态 | 当前功率限制原因（位标志） | R |
| 0x1010 | 检锅脉冲 | 检锅脉冲计数值 | R |
| 0x1011 | 谐振电流 AD | 谐振电流采样值 | R |
| 0x1012 | 反压计数器 | IGBT 反压计数 | R |
| 0x1013 | 频率计数器 | 工作频率计数 | R |
| 0x1014 | 丢波计数器 | 丢波计数 | R |
| 0x1015 | 相位值 | 当前相位值 | R |
| 0x1016 | 故障码 | 当前故障码 | R |
| 0x1017 | 内部故障 | 异常停机原因（故障码解释） | R |
| 0x1018 | 主板版本号 | 从机固件版本 | R |
| 0x1019 | 等效电阻 | 等效电阻 = 母线电流 / 谐振电流² | R |
| 0x1020 | 25W 修正值 | 小功率修正参数 | R |

> 注：0x1016~0x1020 预留，主机暂不处理。

### 4.2 可读写寄存器 (0x2000 - 0x2013) — 初始化参数

> 上电时主机下发，或当从机状态位 bit7=0 时重新下发。
> 如从机不支持某参数，返回 0xFFFF。

| 地址 | 名称 | 说明 | R/W | 设定范围 |
|---|---|---|---|---|
| 0x2000 | 检锅强度设定 | 高8bit=检锅间隔时间(s)，低8bit=检锅强度 | R/W | — |
| 0x2001 | 最大 PPG 限制 | PPG 上限值 | R/W | — |
| 0x2002 | 移锅功率 | 移锅检测功率阈值 | R/W | — |
| 0x2003 | 反压限制 | IGBT 反压保护阈值 | R/W | — |
| 0x2004 | 负载有效电流 | 负载有效电流阈值 | R/W | — |
| 0x2005 | 电流修正系数 | 电流采样修正系数 | R/W | — |
| 0x2006 | 最小连续功率 | 连续加热最小功率 | R/W | — |
| 0x2007 | 最大连续功率 | 连续加热最大功率 | R/W | — |
| 0x2008 | 恶略锅具保护功率 | 恶劣锅具保护阈值（**半桥专属参数**） | R/W | — |
| 0x2009 | 谐振电流保护值 | 谐振电流过流保护阈值 | R/W | — |
| 0x2010 | 移锅相位 | 移锅检测相位阈值 | R/W | — |
| 0x2011 | 最小相位 | 正常工作最小相位值 | R/W | — |
| 0x2012 | 钢铁锅修正 | 钢铁锅材质修正系数 | R/W | — |
| 0x2013 | 移锅谐振电流限制 | 移锅时的谐振电流限制值 | R/W | — |

### 4.3 可读写寄存器 (0x2014 - 0x2020) — 实时控制指令

> 正常工作时，主机以 100ms 周期下发控制。

| 地址 | 名称 | 说明 | R/W |
|---|---|---|---|
| 0x2014 | 工作状态 | Bit 控制（见下方详解） | R/W |
| 0x2015 | 风扇转速 | 风扇 PWM 转速值 | R/W |
| 0x2016 | 目标功率 | 设定加热功率 | R/W |
| 0x2017 | 间断加热 | 高8bit=加热时间(0.1s)，低8bit=停止时间(0.1s) | R/W |
| 0x2018 | 抖频参数 | 抖频功能参数 | R/W |
| 0x2019 | 蜂鸣器控制 | 蜂鸣器鸣叫控制 | R/W |
| 0x2020 | 谐振电流短路保护 | 谐振电流短路保护阈值 | R/W |

### 4.4 0x2014 工作状态 Bit 定义

| Bit | 名称 | 说明 |
|---|---|---|
| bit0 | 设备总开关 | 0=关闭，1=开启 |
| bit1 | 风机开关 | 0=关闭，1=开启 |
| bit2 | 间断加热 | 0=连续加热，1=间断加热模式 |
| bit3 | 加热/检锅控制 | 0=停止加热，1=停止加热但保持检锅 |
| bit4 | 核心电压选择 | 0=110V，1=220V |
| bit5-7 | 保留 | — |

**工作状态组合示例：**

| bit0 | bit1 | bit2 | bit3 | 含义 |
|---|---|---|---|---|
| 0 | 0 | 0 | 0 | 完全关闭 |
| 1 | 1 | 0 | 0 | 正常加热 |
| 1 | 1 | 1 | 0 | 间断加热模式 |
| 1 | 1 | 0 | 1 | 停止加热，保持检锅 |
| 1 | 0 | 0 | 0 | 风机异常（仅加热无散热） |

### 4.5 校准/配置寄存器 (0x3000 - 0x3550)

| 地址 | 名称 | 说明 | R/W | 默认值 |
|---|---|---|---|---|
| 0x3000 | 功率校准值 | 0~255，写入 0x55AA → 从机应答 0xAABB 表示成功 | R/W | 0.0 |
| 0x3001 | 从机地址设置 | 1~255 | R/W | 1.0 |
| 0x3002 | 波特率设置 | 写入值少一位，如 115200→11520，57600→5760 | R/W | 5760.0 |
| 0x3003 | 目标炉头选择 | 1~8（相当于批量设置多炉头通道的参数） | R/W | 1.0 |
| 0x3550 | 保存命令 | 写入任意值保存 0x3000 区域的所有内容到非易失存储器 | R/W | — |

> **0x3000 功率校准流程：**
> 1. 主机读 0x3000 → 得到当前校准值
> 2. 主机写 0x3000 为 0x55AA → 从机应答 0xAABB 表示写入模式就绪
> 3. 主机写入新的校准值
> 4. 主机写 0x3550（保存命令）→ 从机保存到非易失存储
> 5. 下次上电从机自动加载保存值

## 5. 通信流程

### 5.1 上电初始化流程

```
主机上电
  │
  ├── 轮询站号 5, 10, 15, 20 (分别对应炉头1~4)
  │    读 0x1000 (系统状态)
  │    │
  │    ├── bit7=1 (初始化完成)
  │    │     → 正常控制模式
  │    │
  │    └── bit7=0 (未初始化)
  │          → 下发初始化参数 (0x2000 ~ 0x2013)
  │          → 等待下次轮询确认初始化完成
  │
  └── 所有炉头通道初始化完成后 → 进入正常工作循环
```

### 5.2 正常工作循环 (100ms)

```
每 100ms 执行一次：
  │
  ├── 读 0x1000 (系统状态)        — 检查 bit7 初始化标志
  ├── 读 0x1001~0x1015           — 采集电压/电流/温度/功率等状态
  │
  ├── 若状态位 bit7=0：
  │     ├── 重新下发初始化参数 (0x2000~0x2013)
  │     └── 跳过控制指令下发
  │
  └── 若状态位 bit7=1：
        ├── 写 0x2014 (工作状态)   — 设置开关/风机/加热模式
        ├── 写 0x2015 (风扇转速)   — 设置风扇速度
        ├── 写 0x2016 (目标功率)   — 设置目标功率
        └── 可选：写 0x2017~0x2020
```

### 5.3 4炉头通道轮询策略

主机为 4 个炉头通道分别维护独立的状态机，通过站号区分。每 100ms 轮询一个通道，或以更高速率逐个循环轮询。

| 炉头通道 | 站号 | 备注 |
|---|---|---|
| 炉头 1 | 5 | — |
| 炉头 2 | 10 | — |
| 炉头 3 | 15 | — |
| 炉头 4 | 20 | — |

**推荐轮询时序示例 (100ms 周期)：**
```
t=0ms     → 轮询站号5 (炉头1, 读0x1000~0x1015) → 下发控制
t=15ms    → 轮询站号10 (炉头2, 读+写)
t=30ms    → 轮询站号15 (炉头3, 读+写)
t=45ms    → 轮询站号20 (炉头4, 读+写)
t=60~100ms → 其他系统任务
```

## 6. 典型数据帧示例

### 6.1 读炉头1 (站号=5, 0x05) 的系统状态 0x1000

**主机发送：**
```
0x05  0x03  0x10  0x00  0x00  0x01  CRC低  CRC高
│     │     │     │     │     │
│     │     │     │     │     └── 寄存器个数 = 1
│     │     │     │     └──────── 起始地址低8 = 0x00
│     │     │     └────────────── 起始地址高8 = 0x10 → 0x1000
│     │     └──────────────────── 功能码 = 0x03
│     └────────────────────────── 站号 = 5 (炉头1)
└──────────────────────────────── CRC
```

**从机应答（初始化完成）：**
```
0x05  0x03  0x02  0x80  0x00  CRC低  CRC高
│     │     │     │     │
│     │     │     │     └── 数据低8
│     │     │     └──────── 数据高8 = 0x80 → bit7=1 初始化完成
│     │     └────────────── 字节数 = 2
│     └──────────────────── 功能码 = 0x03
└────────────────────────── 站号 = 5 (炉头1)
```

### 6.2 写炉头2 (站号=10, 0x0A) 目标功率 0x2016 = 1000W

**主机发送：**
```
0x0A  0x06  0x20  0x16  0x03  0xE8  CRC低  CRC高
│     │     │     │     │     │
│     │     │     │     │     └── 数据低8 = 0xE8 → 1000
│     │     │     │     └──────── 数据高8 = 0x03
│     │     │     └────────────── 地址低8 = 0x16
│     │     └──────────────────── 地址高8 = 0x20 → 0x2016
│     └────────────────────────── 功能码 = 0x06
└──────────────────────────────── 站号 = 10 (炉头2)
```

## 7. 注意事项

1. **字节间隔**：帧内字节间隔不得超过 1.5 字符时间，否则从机视为帧结束（出错）。
2. **帧间隔**：两帧之间至少间隔 10ms  时间。
3. **CRC 校验**：使用标准 Modbus CRC-16 (多项式 0x8005)，低字节在前。
4. **无应答处理**：炉头通道无应答时，主机应重试 3 次，仍无应答则标记该通道离线。
5. **全总线共享**：4个炉头通道共用同一 UART 总线，必须严格按 Modbus 站号寻址，不允许无地址广播。
6. **初始化参数重发**：主机必须持续监测每个炉头通道 0x1000 的 bit7，一旦为 0 立即重发初始化参数。
