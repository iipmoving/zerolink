## 🎯 基础提示词（完整版）

```
请为我生成一个EMC面板模拟器的JSON配置文件。

## 画布规格
- Canvas尺寸: 1024x600像素
- 有效布局区域: X(50-974), Y(50-550)
- 坐标系: 左上角(0,0)，向右X增加，向下Y增加

## 控件类型与默认规格

### 1. 按键 (Button)
- 默认尺寸: 宽40px, 高40px
- 颜色: bg_color="#2a2a2a", border_color="#555555", text_color="#cccccc"
- 命名: "开始 / 暂停", "加水", "加时间", "M1"-"M10", "电源"

### 2. LED灯 (LED Indicator)
- 默认尺寸: 宽10px, 高10px
- 颜色: bg_color="#333333", border_color="#555555", text_color="#cccccc"
- 命名: "XXX灯"，位于对应按键上方20-30px

### 3. 数码管 (Seven-Segment Display)
- 默认尺寸: 宽202px, 高55px（四位显示）
- 颜色: bg_color="#111111", border_color="#555555", text_color="#44ff44"
- 命名: "四位主显示"
- 位置: 居中放置 X=400-420, Y=270-300

## 布局要求
【在这里描述你的具体需求】

例如：
- 需要3个功能键：开始/暂停、加水、加时间，放在底部Y=276
- 每个按键上方需要有对应的LED指示灯，Y=190
- 中间需要一个四位数码管显示，居中放置
- 按键水平间隔100px

## 间距规范
- 控件之间最小间距: 10px
- 同类型控件水平间隔: 100-120px
- 同类型控件垂直间隔: 80-100px
- LED与对应按键垂直距离: 20-30px

## 输出格式
请严格按照以下JSON格式输出：

{
  "controls": [
    {
      "type": "按键|LED灯|数码管",
      "x": 整数坐标,
      "y": 整数坐标,
      "name": "控件名称",
      "width": 宽度,
      "height": 高度,
      "bg_color": "#RRGGBB",
      "border_color": "#RRGGBB",
      "text_color": "#RRGGBB"
    }
  ]
}

## 验证要求
生成后请确保：
1. 所有控件在画布范围内（X: 50-974, Y: 50-550）
2. 控件之间没有重叠
3. LED灯位于对应按键上方
4. JSON格式正确
```

## 💡 优化建议

### 提高生成质量的技巧

1. **明确数量**: "需要3个按键"比"需要一些按键"更好
2. **指定坐标**: "Y=276"比"放在底部"更精确
3. **提供参考**: "参考new.json的布局"
4. **分步生成**: 先生成按键，再生成LED，最后合并
5. **要求验证**: "生成后请验证坐标范围"

### 常见错误避免

❌ **模糊描述**: "把按键放得好看一点"
✅ **精确描述**: "按键水平间隔100px，垂直居中对齐"

❌ **缺少规格**: "添加一个显示"
✅ **完整规格**: "添加一个四位数码管，宽202px，高55px"

❌ **忽略间距**: "把所有控件放在一起"
✅ **考虑间距**: "控件之间保持至少10px间距"
