# 按键测试指南

## 🎯 问题诊断

### 现象
点击按键后没有反应，状态保持在S_SHUTDOWN（关机状态）

### 原因
在**S_SHUTDOWN（关机）状态**下，只有特定的按键才能触发状态转换：
- ✅ **KEY_POWER (0)** - 电源键短按
- ✅ **KEY_START_PAUSE (13)** - "开始/暂停"键短按
- ❌ 其他按键（如加水、加时间、M1-M10）在此状态下无效

---

## 📋 正确的操作流程

### 步骤1：开机
**点击"开始 / 暂停"键**（不是加水键！）
- 预期：状态从 S_SHUTDOWN → S_STANDBY（待机）
- 数码管显示：88:88 或其他初始值
- LED：电源灯亮起

### 步骤2：选择功能
在待机状态下，点击 M1/M2/M3 等功能键
- 预期：状态从 S_STANDBY → S_FUNC_SELECT
- 数码管显示：选中的功能参数

### 步骤3：开始烹饪
点击"开始 / 暂停"键
- 预期：状态从 S_FUNC_SELECT → S_COOKING
- 数码管开始倒计时

### 步骤4：调整参数（可选）
在待机或功能选择状态下：
- 点击"加水"键：增加水量
- 点击"加时间"键：增加时间

### 步骤5：关机
长按"开始 / 暂停"键（>1.5秒）
- 预期：状态从任意状态 → S_SHUTDOWN

## 🧪 快速测试流程

### 测试1：基本开关机
```
1. 点击"开始 / 暂停" → 开机（S_SHUTDOWN → S_STANDBY）
2. 长按"开始 / 暂停" → 关机（S_STANDBY → S_SHUTDOWN）

```


## ⚠️ 常见错误

### 错误1：点击"加水"键没反应
**原因**：当前是S_SHUTDOWN状态，加水键无效  
**解决**：先点击"开始 / 暂停"键开机

### 错误2：点击M1-M10没反应
**原因**：当前是S_SHUTDOWN状态  
**解决**：先点击"开始 / 暂停"键开机

### 错误3：短按无法关机
**原因**：关机需要长按（>1.5秒）  
**解决**：按住"开始 / 暂停"键超过1.5秒

## 🔍 调试技巧

### 查看当前状态
打开浏览器控制台（F12），搜索：
```
state=
```
会看到类似输出：
```
[EmcLogic] runCycle #450: state=2(S_SHUTDOWN)
```

### 查看按键事件
搜索：
```
pressKey
```
会看到：
```
[JSEmcLogicAdapter.pressKey] 发送按键事件: {keyCode: 13, event: 1, eventName: 'PRESS'}
```

### 查看状态转换
搜索：
```
状态转换
```
会看到：
```
[EmcLogic] 状态转换: S_SHUTDOWN → S_STANDBY
```
