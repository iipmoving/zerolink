# 面板WASM集成 - 按键问题修复说明

## 🔧 问题描述

**现象**: 初始化WASM后，点击Canvas上的按键无效，没有任何反应。

**根本原因**: 
- WASM初始化后没有启动周期运行（`startCycle`）
- C代码需要持续调用`emc_run_cycle()`才能处理按键事件和状态转换
- 上电自检流程也需要周期驱动（S_POWER_ON → S_VERSION → S_SHUTDOWN）

---

## ✅ 解决方案

### 修改文件: `panel_with_wasm.html`

**关键改动1**: 初始化时自动启动周期运行

```javascript
async function initialize() {
    // ... WASM初始化代码 ...
    
    // ✅ 自动启动周期运行（关键！）
    log('\n🔄 自动启动周期运行...');
    cycleCount = 0;
    adapter.startCycle(() => {
        cycleCount++;
        
        // 每50个周期更新一次显示
        if (cycleCount % 50 === 0) {
            updateDisplay();
            document.getElementById('cycleCount').textContent = cycleCount;
        }
    });
    log('✅ 周期运行已启动，系统将自动执行上电自检');
}
```

**关键改动2**: 添加清晰的操作提示

```javascript
log('⚠️ 注意：上电后会自动进入自检流程（约3秒）');
log('   等待显示"---"后，点击电源键即可开机');
```

**关键改动3**: 优化点击反馈

```javascript
function handleCanvasClick(event) {
    if (binder.handleCanvasClick(x, y)) {
        log(`👆 点击坐标: (${x.toFixed(0)}, ${y.toFixed(0)})`);
        
        // 立即更新显示（缩短延迟）
        setTimeout(() => {
            updateDisplay();
            const state = adapter.getState();
            const stateName = adapter.STATE_NAMES[state] || `UNKNOWN(${state})`;
            log(`   当前状态: ${stateName}`);
        }, 50);  // 从100ms缩短到50ms
    } else {
        log(`❌ 点击位置无效: (${x.toFixed(0)}, ${y.toFixed(0)})`);
    }
}
```

## 🎯 关键技术点

### 1. 周期运行的必要性

WASM中的C代码是**被动执行**的，需要外部持续调用：

```c
// C代码逻辑
void emc_run_cycle(void) {
    // 1. 检查按键状态
    // 2. 执行状态机转换
    // 3. 更新显示输出
    // 4. 更新LED状态
}
```

**如果不启动周期运行**:
- ❌ 按键事件无法被检测
- ❌ 状态机不会转换
- ❌ 显示不会更新
- ❌ LED状态不变

### 2. 上电自检流程

C代码中的状态机设计：

```
S_POWER_ON (0)
    ↓ 等待1.5秒
S_VERSION (1)
    ↓ 等待1.5秒
S_SHUTDOWN (2)  ← 在此状态下按POWER键才能开机
    ↓ 按POWER键
S_STANDBY (4)
    ↓ 按M1-M10
S_FUNC_SELECT (5)
```

### 3. 按键处理机制

```javascript
// 1. Canvas点击事件
canvas.addEventListener('click', handleCanvasClick);

// 2. 识别按键
binder.handleCanvasClick(x, y) {
    // 遍历所有按键，检查坐标是否在范围内
    if (x >= key.x && x <= key.x + key.width &&
        y >= key.y && y <= key.y + key.height) {
        // 发送按键事件到WASM
        adapter.clickKey(keyCode, 50);
    }
}

// 3. WASM处理按键
adapter.clickKey(keyCode, holdTime) {
    this.pressKey(keyCode, EVENT_PRESS);  // 按下
    this.runCycle();                       // 运行周期
    await sleep(holdTime);                 // 等待
    this.pressKey(keyCode, EVENT_RELEASE); // 释放
    this.runCycle();                       // 运行周期
}
```

## 🐛 常见问题

### Q1: 点击按键没反应？

**检查清单**:
1. ✅ 是否已点击"初始化WASM"？
2. ✅ 是否已点击"绑定控件"？
3. ✅ 控制台是否有错误信息？
4. ✅ 周期计数是否在增加？（说明周期正在运行）

**解决方法**:
- 查看浏览器控制台（F12）
- 确认日志中有"✅ 周期运行已启动"
- 确认cycleCount数字在不断增加

### Q2: 上电后直接点击功能键无效？

**原因**: 必须先经过关机状态（S_SHUTDOWN）

**正确操作**:
1. 等待上电自检完成（显示"---"）
2. 点击"电源"键开机
3. 进入待机状态（显示"00"）
4. 再点击功能键

### Q3: 数码管显示不更新？

**可能原因**:
- 周期运行未启动
- 更新频率太低（默认每50周期更新一次）

**解决方法**:
- 确认cycleCount在增加
- 检查updateDisplay()是否被调用
- 查看控制台是否有错误
