# EMC面板配置JSON格式规范

## 📋 文档概述

本文档定义了EMC面板模拟器使用的JSON配置格式，用于AI自动生成界面布局。

---

## 🎯 完整JSON结构

```json
{
  "controls": [
    {
      "type": "按键|LED灯|数码管",
      "x": 整数,
      "y": 整数,
      "name": "字符串",
      "width": 整数,
      "height": 整数,
      "bg_color": "#RRGGBB",
      "border_color": "#RRGGBB",
      "text_color": "#RRGGBB"
    }
  ],
  "background_image": "文件名.png",
  "background_image_path": "完整路径"
}
```

---

## 📐 Canvas画布规格

### 标准尺寸
- **宽度**: 1024像素
- **高度**: 600像素
- **坐标系**: 左上角为(0, 0)，向右X增加，向下Y增加

### 有效布局区域
- **X轴范围**: 50 - 974（左右各留50px边距）
- **Y轴范围**: 50 - 550（上下各留50px边距）

---

## 🎨 控件类型与默认规格

### 1. 按键 (Button)

**用途**: 用户交互按钮

**默认尺寸**:
- 宽度: 40px
- 高度: 40px

**颜色规范**:
- 背景色: `#2a2a2a` (深灰色)
- 边框色: `#555555` (中灰色)
- 文字色: `#cccccc` (浅灰色)

**命名规范**:
- 功能键: "开始 / 暂停", "加水", "加时间"
- 菜单键: "M1", "M2", ..., "M10"
- 电源键: "电源"

**布局建议**:
- 垂直排列时，Y坐标间隔: 80-100px
- 水平排列时，X坐标间隔: 100-120px
- 底部功能区Y坐标: 270-350
- 顶部菜单区Y坐标: 100-200

**示例**:
```json
{
  "type": "按键",
  "x": 99,
  "y": 276,
  "name": "开始 / 暂停",
  "width": 40,
  "height": 40,
  "bg_color": "#2a2a2a",
  "border_color": "#555555",
  "text_color": "#cccccc"
}
```

---

### 2. LED灯 (LED Indicator)

**用途**: 状态指示灯

**默认尺寸**:
- 宽度: 10px
- 高度: 10px

**颜色规范**:
- 背景色: `#333333` (关闭状态)
- 边框色: `#555555`
- 文字色: `#cccccc` (通常不显示文字)

**命名规范**:
- 对应按键: "开始 / 暂停灯", "加水灯", "加时间灯"
- 菜单指示: "M1 灯", "M2 灯", ..., "M10 灯"
- 功能指示: "mL 指示灯", "定时指示灯", "电源灯"

**布局建议**:
- 位于对应按键上方20-30px
- X坐标与对应按键中心对齐
- Y坐标通常在180-200范围内

**示例**:
```json
{
  "type": "LED灯",
  "x": 113,
  "y": 190,
  "name": "开始 / 暂停灯",
  "width": 10,
  "height": 10,
  "bg_color": "#333333",
  "border_color": "#555555",
  "text_color": "#cccccc"
}
```

---

### 3. 数码管 (Seven-Segment Display)

**用途**: 数字显示区域

**默认尺寸**:
- 宽度: 202px (四位显示)
- 高度: 55px

**颜色规范**:
- 背景色: `#111111` (黑色)
- 边框色: `#555555`
- 文字色: `#44ff44` (绿色LED效果)

**命名规范**:
- "四位主显示"
- "温度显示"
- "时间显示"

**布局建议**:
- 居中放置: X = 400-420
- Y坐标: 270-300 (中部区域)
- 确保有足够的显示空间

**示例**:
```json
{
  "type": "数码管",
  "x": 401,
  "y": 282,
  "name": "四位主显示",
  "width": 202,
  "height": 55,
  "bg_color": "#111111",
  "border_color": "#555555",
  "text_color": "#44ff44"
}
```

## 🎯 典型布局模式

### 模式1: 底部功能键 + 顶部菜单键

```
布局结构:
┌─────────────────────────────────────┐
│  M1  M2  M3  ...  M10  (Y: 100-150) │
│  ●   ●   ●        ●                 │  ← LED指示灯 (Y: 180-200)
│                                     │
│         [数码管显示]  (Y: 270-300)   │
│                                     │
│  START  ADD_W  ADD_T  (Y: 270-350)  │  ← 功能按键
└─────────────────────────────────────┘
```

**坐标示例**:
- M1-M10: Y=120, X间隔100px (从100到1000)
- LED灯: Y=190, X与对应M键对齐
- 数码管: X=401, Y=282
- 功能键: Y=276, X间隔100-110px

---

### 模式2: 左侧功能键 + 右侧菜单键

```
布局结构:
┌─────────────────────────────────────┐
│  START  ADD_W  ADD_T    M1  M2  M3  │
│    ●      ●      ●      ●   ●   ●   │
│                                     │
│         [数码管显示]                 │
│                                     │
│  POWER  CANCEL            M4  M5    │
│    ●                     ●   ●      │
└─────────────────────────────────────┘
```

---

## 📏 间距规范

### 最小间距
- 控件之间: ≥10px
- 控件与边界: ≥20px
- LED与对应按键: 20-30px

### 推荐间距
- 同类型控件水平间隔: 100-120px
- 同类型控件垂直间隔: 80-100px
- 不同功能区间隔: 150-200px

## 🎨 颜色规范

### 标准配色方案

| 元素 | 颜色代码 | 说明 |
|------|---------|------|
| 按键背景 | `#2a2a2a` | 深灰色 |
| 按键边框 | `#555555` | 中灰色 |
| 按键文字 | `#cccccc` | 浅灰色 |
| LED关闭 | `#333333` | 暗灰色 |
| LED边框 | `#555555` | 中灰色 |
| 数码管背景 | `#111111` | 黑色 |
| 数码管边框 | `#555555` | 中灰色 |
| 数码管显示 | `#44ff44` | 绿色LED |

### 可选配色

**暖色调**:
- 数码管显示: `#ff4444` (红色)
- 数码管显示: `#ffaa00` (橙色)

**冷色调**:
- 数码管显示: `#44aaff` (蓝色)
- 数码管显示: `#44ffaa` (青色)

## 🔧 高级配置选项

### 长按功能按键

某些按键需要支持长按功能（如关机键），可以在配置中添加：

```json
{
  "type": "按键",
  "x": 99,
  "y": 276,
  "name": "开始 / 暂停",
  "width": 40,
  "height": 66,
  "bg_color": "#2a2a2a",
  "border_color": "#555555",
  "text_color": "#cccccc",
  "long_press": true
}
```

**注意**: `long_press`字段是可选的，默认为`false`。

## ✅ 验证清单

生成JSON后，请检查：

- [ ] 所有控件的X坐标在50-974范围内
- [ ] 所有控件的Y坐标在50-550范围内
- [ ] 控件之间没有重叠（间距≥10px）
- [ ] LED灯位于对应按键上方20-30px
- [ ] 数码管有足够的显示空间（宽度≥150px）
- [ ] 颜色代码格式正确（#RRGGBB）
- [ ] 控件名称清晰易懂
- [ ] JSON格式语法正确

## 🚀 AI生成建议

### 提示词要点

1. **明确控件数量**: "生成包含3个按键、3个LED灯、1个数码管的配置"
2. **指定布局模式**: "使用底部功能键+顶部菜单键的布局"
3. **提供坐标参考**: "按键放在Y=276，LED放在Y=190"
4. **遵循颜色规范**: "使用标准配色方案"
5. **保持间距合理**: "控件间隔100px"

### 常见错误

❌ **错误**: 控件超出画布边界
✅ **正确**: 确保X<974, Y<550

❌ **错误**: LED与按键距离太远
✅ **正确**: LED在按键上方20-30px

❌ **错误**: 数码管宽度太小
✅ **正确**: 四位显示宽度≥200px
