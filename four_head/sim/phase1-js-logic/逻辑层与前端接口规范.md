# EMC面板逻辑层与前端接口规范

## 📋 文档概述

本文档定义了EMC面板模拟器的逻辑层接口和前端调用接口，作为生成新界面的基础参考。

---

## 🎯 架构设计

```
┌─────────────────────────────────────┐
│         前端UI层 (index.html)        │
│  - Canvas渲染                        │
│  - 控件交互                          │
│  - 属性编辑                          │
└──────────────┬──────────────────────┘
               │ LogicLayerAdapter
               │ (统一接口)
┌──────────────▼──────────────────────┐
│       逻辑层适配器 (Adapter)          │
│  - JS逻辑层适配器                    │
│  - WASM逻辑层适配器                  │
│  - DLL逻辑层适配器                   │
└──────────────┬──────────────────────┘
               │ 底层实现
┌──────────────▼──────────────────────┐
│      逻辑层实现 (Logic Layer)        │
│  - emc_logic_js.js (JS版本)         │
│  - emc_test.wasm (WASM版本)         │
│  - emc_logic.dll (DLL版本)          │
└─────────────────────────────────────┘
```

**核心原则**：单向数据流
- UI → Adapter → Logic（输入）
- Logic → Adapter → UI（输出）
- 前端不直接操作逻辑层内部状态

## 🔧 逻辑层接口定义

### LogicLayerAdapter 基类

所有逻辑层适配器必须继承此类并实现以下方法：

#### 1. 初始化与清理

```javascript
/**
 * 初始化逻辑层
 * @returns {Promise<void>}
 */
async init() {
    throw new Error('init() must be implemented by subclass');
}

/**
 * 清理资源
 */
cleanup() {
    this.stopCycle();
    this.initialized = false;
}
```

**使用示例**：
```javascript
const adapter = new JSLogicLayerAdapter();
await adapter.init();  // 必须等待初始化完成

// 页面卸载时清理
window.addEventListener('beforeunload', () => {
    adapter.cleanup();
});
```

---

#### 2. 回调注册

```javascript
/**
 * 注册回调函数
 * @param {Function} dispCb - 显示输出回调 (segPtr, ledPtr) => void
 * @param {Function} buzzerCb - 蜂鸣器回调 (cmd) => void
 * @param {Function} statusCb - 状态变化回调 (type, value) => void
 * @param {Function} hwCb - 硬件输入回调 (hwPtr) => void
 */
registerCallbacks(dispCb, buzzerCb, statusCb, hwCb)
```

**参数说明**：
- `dispCb`: 数码管和LED更新回调
  - `segPtr`: 数码管段码指针/数组 `[seg0, seg1, seg2, seg3]`
  - `ledPtr`: LED状态指针/对象 `{ led_power: 0/1, led_heat: 0/1 }`
  
- `buzzerCb`: 蜂鸣器控制回调
  - `cmd`: 命令值，0=关闭，1=开启
  
- `statusCb`: 状态变化回调
  - `type`: 变化类型 ('state', 'mode', 'error')
  - `value`: 新值
  
- `hwCb`: 硬件输入更新回调（可选）
  - `hwPtr`: 硬件输入指针/对象

**使用示例**：
```javascript
adapter.registerCallbacks(
    // 显示输出回调
    (segPtr, ledPtr) => {
        // 更新数码管显示
        updateSegmentDisplay(segPtr);
        // 更新LED显示
        updateLedDisplay(ledPtr);
    },
    // 蜂鸣器回调
    (cmd) => {
        if (cmd === 1) {
            playBeepSound();
        } else {
            stopBeepSound();
        }
    },
    // 状态变化回调
    (type, value) => {
        if (type === 'state') {
            console.log('状态变为:', getStateName(value));
        }
    },
    // 硬件输入回调（可选）
    (hwPtr) => {
        // 同步硬件输入状态
    }
);
```

#### 3. 周期运行

```javascript
/**
 * 运行单个周期
 */
runCycle() {
    throw new Error('runCycle() must be implemented by subclass');
}

/**
 * 启动周期运行
 * @param {Function} onCycle - 每个周期结束时的回调
 * @param {number} interval - 周期间隔（毫秒），默认10ms
 */
startCycle(onCycle, interval = 10)

/**
 * 停止周期运行
 */
stopCycle()
```

**使用示例**：
```javascript
// 启动自动运行（每10ms一个周期）
adapter.startCycle(() => {
    // 每个周期结束后执行
    renderCanvas();  // 刷新界面
}, 10);

// 手动运行单个周期
adapter.runCycle();
renderCanvas();

// 停止运行
adapter.stopCycle();
```

**注意事项**：
- 默认间隔为10ms（100Hz），符合实时控制要求
- `onCycle`回调在`runCycle()`之后执行
- 避免在`onCycle`中执行耗时操作

#### 4. 按键输入

```javascript
/**
 * 模拟按键按下
 * @param {number} keyCode - 按键代码
 * @param {number} eventType - 事件类型（短按/长按/释放）
 */
pressKey(keyCode, eventType)
```

**参数说明**：
- `keyCode`: 按键枚举值（对应C代码中的枚举）
  - 例如：`KEY_START_PAUSE`, `KEY_ADD_WATER`, `KEY_TIME`等
  
- `eventType`: 事件类型
  - `0`: 按键按下（PRESS）
  - `1`: 按键释放（RELEASE）
  - `2`: 长按触发（LONG_PRESS）

**使用示例**：
```javascript
// 短按"开始/暂停"键
adapter.pressKey(KEY_START_PAUSE, 0);  // 按下
setTimeout(() => {
    adapter.pressKey(KEY_START_PAUSE, 1);  // 释放
}, 100);

// 长按"加水"键
adapter.pressKey(KEY_ADD_WATER, 0);  // 按下
setTimeout(() => {
    adapter.pressKey(KEY_ADD_WATER, 2);  // 长按触发
}, 2000);
setTimeout(() => {
    adapter.pressKey(KEY_ADD_WATER, 1);  // 释放
}, 2500);
```

**前端集成**：
```javascript
// Canvas点击事件
canvas.addEventListener('click', (e) => {
    const control = hitTest(e.offsetX, e.offsetY);
    if (control && control.type === 'button') {
        const keyCode = getKeyCodeFromControl(control);  // 从控件获取键码
        adapter.pressKey(keyCode, 0);  // 按下
        setTimeout(() => {
            adapter.pressKey(keyCode, 1);  // 释放
        }, 100);
    }
});
```

#### 5. 状态查询

```javascript
/**
 * 获取当前状态码
 * @returns {number} 状态码
 */
getState()

/**
 * 获取显示输出
 * @returns {Object} { seg: [4], dp: number, colon: number, display: string }
 */
getDisplay()

/**
 * 获取LED状态
 * @returns {Object} LED状态对象
 */
getLedState()

/**
 * 获取状态名称映射表
 * @returns {Object} { stateCode: stateName }
 */
getStateNames()
```

**返回值说明**：

`getState()`:
- 返回整数状态码
- 对应C代码中的状态枚举
- 例如：`0`=待机，`1`=加热，`2`=保温等

`getDisplay()`:
```javascript
{
    seg: [0x3F, 0x06, 0x5B, 0x4F],  // 4位数码管段码
    dp: 0x00,                         // 小数点位掩码
    colon: 0,                         // 冒号状态（0/1）
    display: "12:30"                  // 可读字符串（可选）
}
```

`getLedState()`:
```javascript
{
    led_power: 1,     // 电源灯（0=灭，1=亮）
    led_heat: 0,      // 加热灯
    led_keepwarm: 1   // 保温灯
}
```

`getStateNames()`:
```javascript
{
    0: "STANDBY",
    1: "HEATING",
    2: "KEEP_WARM",
    3: "COOKING",
    ...
}
```

**使用示例**：
```javascript
// 获取当前状态
const stateCode = adapter.getState();
const stateNames = adapter.getStateNames();
console.log('当前状态:', stateNames[stateCode]);

// 获取显示内容
const display = adapter.getDisplay();
updateSegmentDisplay(display.seg);

// 获取LED状态
const leds = adapter.getLedState();
updateLedIndicator('power', leds.led_power);
```

### 控件管理

#### 添加控件

```javascript
/**
 * 添加新控件
 * @param {string} type - 控件类型：'button'/'led'/'segment'

 * @returns {object} 新创建的控件

function addControl(type, options = {})
```

**参数说明**：
- `type`: 
  - `'button'`: 按键（默认40×40px）
  - `'led'`: LED指示灯（默认10×10px）

  ```javascript
  {
      name: "新按键",           // 名称
      x: 100,                  // X坐标
      y: 100,                  // Y坐标
      width: 40,               // 宽度（可选，使用默认值）
      height: 40,              // 高度（可选，使用默认值）
      config: {
          key_code: "",        // 键码（可选）
          long_press: false    // 长按支持（仅按键）
      }
  }
  ```

**使用示例**：
```javascript
// 添加按键
const btn = addControl('button', {
    name: "开始",
    x: 50,
    y: 50,
    config: {

    y: 50
```

**绘制方法**：
```javascript
function drawButton(ctx, control, isSelected) {
    const { x, y, width, height, style } = control;
    
    // 绘制背景
    ctx.fillStyle = style.background_color;
    ctx.beginPath();
    ctx.roundRect(x, y, width, height, style.border_radius);
    ctx.fill();
    
    // 绘制边框
    ctx.strokeStyle = style.border_color;
    ctx.lineWidth = style.border_width;
    ctx.stroke();
    
    // 绘制文字
    ctx.fillStyle = style.text_color;
    ctx.font = `${style.font_size}px Arial`;
    ctx.textAlign = 'center';
    ctx.textBaseline = 'middle';
    ctx.fillText(control.name, x + width / 2, y + height / 2);
    
    // 选中高亮
    if (isSelected) {
        ctx.strokeStyle = '#0078ff';
        ctx.lineWidth = 2;
        ctx.setLineDash([5, 3]);
        ctx.strokeRect(x - 2, y - 2, width + 4, height + 4);
        ctx.setLineDash([]);
    }
}
```

**交互处理**：
```javascript
// 单击：短按

    if (pressTimer) {
        clearTimeout(pressTimer);
        pressTimer = null;
    }
});
```

```javascript
function drawLed(ctx, control, isSelected, isOn) {
    const { x, y, width, height, style } = control;
    
    // 根据状态选择颜色
    const color = isOn ? style.color_on : style.color_off;
    
    // 绘制圆形LED
    ctx.fillStyle = color;
    ctx.beginPath();
    ctx.arc(x + width / 2, y + height / 2, Math.min(width, height) / 2, 0, Math.PI * 2);
    ctx.fill();
    
    // 发光效果（点亮时）
    if (isOn) {
        ctx.shadowColor = color;
        ctx.shadowBlur = 10;
        ctx.beginPath();
        ctx.arc(x + width / 2, y + height / 2, Math.min(width, height) / 2, 0, Math.PI * 2);
        ctx.fill();
        ctx.shadowBlur = 0;
    }
    
    // 选中高亮
    if (isSelected) {
        ctx.strokeStyle = '#0078ff';
        ctx.lineWidth = 2;
        ctx.setLineDash([3, 2]);
        ctx.strokeRect(x - 2, y - 2, width + 4, height + 4);
        ctx.setLineDash([]);
    }
}
```

```javascript
function drawSegment(ctx, control, segData) {
    const { x, y, width, height, style } = control;
    
    // 绘制背景
    ctx.fillStyle = style.bg_color;
    ctx.fillRect(x, y, width, height);
    
    // 绘制4位数码管
    const digitWidth = width / 4;
    for (let i = 0; i < 4; i++) {
        const segCode = segData[i];  // 段码值
        drawSevenSegment(ctx, 
            x + i * digitWidth, y, 
            digitWidth, height, 
            segCode, 
            style.digit_color
        );
    }
    
    // 绘制小数点
    if (segData.dp) {
        drawDecimalPoint(ctx, x, y, width, height, segData.dp);
    }
}
```

**状态更新**：

## ⚠️ 常见错误记录

### 错误1：双击控件无法打开属性编辑器

**现象**：
- 双击Canvas上的控件没有任何反应
- 控制台没有错误信息

**原因**：
浏览器的`dblclick`事件可能被`mousedown`事件干扰，导致无法正确触发。

**解决方案**：
在`mousedown`事件中手动检测双击：

```javascript
let lastClickTime = 0;
let lastClickPos = { x: 0, y: 0 };

function handleEditMouseDown(event) {
    const pos = getMousePos(AppState.canvas, event);
    const control = hitTest(pos.x, pos.y);
    
    // 检测双击：300ms内同一位置点击（误差5px）
    const now = Date.now();
    const isDoubleClick = (now - lastClickTime < 300) && 
                          (Math.abs(pos.x - lastClickPos.x) < 5) &&
                          (Math.abs(pos.y - lastClickPos.y) < 5);
    
    lastClickTime = now;
    lastClickPos = { x: pos.x, y: pos.y };
    
    // 双击打开属性编辑器
    if (isDoubleClick && control) {
        showPropertyEditor(control);
        return;  // 不执行后续的选中/拖拽逻辑
    }
    
    // ... 原有的单击处理逻辑
}
```

### 错误2：属性编辑器模态框不显示

**现象**：
- 双击控件后控制台显示`showPropertyEditor called`
- 但模态框没有弹出
- 检查发现`modal.display`仍然是`none`

**原因**：
HTML中modal有inline style `style="display: none;"`，优先级高于CSS class `.modal.show`。

**解决方案**：
使用JavaScript直接设置style属性：

```javascript
function showPropertyEditor(control) {
    const modal = document.getElementById('property-modal');
    
    // 显示模态框
    modal.classList.add('show');
    modal.style.display = 'flex';  // ✅ 强制覆盖inline style
}

// 关闭时也要清除
function closePropertyEditor() {
    const modal = document.getElementById('property-modal');
    modal.classList.remove('show');
    modal.style.display = 'none';  // ✅ 恢复隐藏
}
```

### 错误3：多选控件单独移动而非整体移动

**现象**：
- Shift+框选多个控件后拖拽
- 只有被点击的控件移动，其他控件不动

**原因**：
MouseDown时只记录了被点击控件的偏移量，MouseMove时只更新了该控件的位置。

**解决方案**：
记录所有选中控件的初始位置，计算统一位移量：

```javascript
// MouseDown时
AppState.dragInitialPositions = {};
AppState.selectedControls.forEach(id => {
    const ctrl = AppState.controls.find(c => c.id === id);
    if (ctrl) {
        AppState.dragInitialPositions[id] = { x: ctrl.x, y: ctrl.y };
    }
});
AppState.dragStartPos = { x: pos.x, y: pos.y };

// MouseMove时
const deltaX = pos.x - AppState.dragStartPos.x;
const deltaY = pos.y - AppState.dragStartPos.y;

AppState.selectedControls.forEach(id => {
    const ctrl = AppState.controls.find(c => c.id === id);
    if (ctrl && AppState.dragInitialPositions[id]) {
        // 基于初始位置 + 位移量
        ctrl.x = AppState.dragInitialPositions[id].x + deltaX;
        ctrl.y = AppState.dragInitialPositions[id].y + deltaY;
        
        // 边界限制
        ctrl.x = clamp(ctrl.x, 0, AppState.canvas.width - ctrl.width);
        ctrl.y = clamp(ctrl.y, 0, AppState.canvas.height - ctrl.height);
    }
});
```

### 错误4：侧边栏列表快速两次单击无效

**现象**：
- Canvas双击可以打开编辑器
- 但侧边栏列表快速两次单击无反应

**原因**：
局部变量`lastClickTime`在每次重新生成列表时被重置。

**解决方案**：
使用全局对象跟踪每个控件的点击时间：

```javascript
// 全局对象，持久化存储
const controlListClickTimes = {};

item.onclick = () => {
    const now = Date.now();
    const lastClickTime = controlListClickTimes[control.id] || 0;
    
    if (control.id === AppState.selectedControlId && (now - lastClickTime) < 300) {
        // 快速第二次点击 → 打开属性编辑器
        showPropertyEditor(control);
    } else {
        // 第一次点击 → 选中
        selectControl(control.id);
        controlListClickTimes[control.id] = now;  // 记录点击时间
    }
};
```

### 错误5：控件超出画布边界

**现象**：
- AI生成的配置中，控件坐标超出画布范围
- 部分控件显示不完整或完全不可见

**原因**：
提示词中没有明确画布尺寸和位置约束。

**解决方案**：
在提示词中添加位置约束说明：

```markdown
## 位置约束（重要）
所有控件必须完全在画布内，不能超出边界：
- 画布尺寸: 1024×600像素
- X坐标范围: 0 ≤ x ≤ (1024 - width)
- Y坐标范围: 0 ≤ y ≤ (600 - height)

例如：
- 按键(40×40): X最大984, Y最大560
- LED灯(10×10): X最大1014, Y最大590
- 数码管(202×55): X最大822, Y最大545
```

同时在代码中添加边界检查：

```javascript
function updateControl(controlId, updates) {
    const control = AppState.controls.find(c => c.id === controlId);
    if (!control) return;
    
    // 边界限制
    if (updates.x !== undefined) {
        updates.x = clamp(updates.x, 0, AppState.canvas.width - control.width);
    }
    if (updates.y !== undefined) {
        updates.y = clamp(updates.y, 0, AppState.canvas.height - control.height);
    }
    
    Object.assign(control, updates);
    renderCanvas();
}
```

## 📝 最佳实践

### 1. 单向数据流

```
✅ 正确：UI → Adapter → Logic
❌ 错误：UI直接修改Logic内部状态
```

**示例**：
```javascript
// ✅ 正确：通过Adapter发送按键
adapter.pressKey(keyCode, 0);

// ❌ 错误：直接修改逻辑层状态
logic.state = NEW_STATE;
```

```javascript
// ✅ 正确：等待初始化完成
async function initApp() {

// ❌ 错误：未等待初始化
adapter.init();
```

```javascript
function moveControl(control, newX, newY) {
```
