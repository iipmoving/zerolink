# 快速开始指南

## 第一步：打开应用

直接用浏览器打开 `index.html` 文件：

```
双击 phase1-js-logic/index.html
```

或者在浏览器中拖入该文件。

**注意：** 由于使用了ES6模块和fetch API，建议使用以下现代浏览器：
- Chrome 80+
- Firefox 75+
- Edge 80+

### 基本操作

**编辑模式：**
1. **拖拽控件**：鼠标点击控件并拖动调整位置
2. **选中控件**：单击控件，边框变蓝表示选中
3. **编辑属性**：双击控件打开属性面板
4. **添加控件**：右侧下拉选择类型，点击"添加"按钮
5. **删除控件**：选中控件后按Delete键
6. **撤销/重做**：Ctrl+Z / Ctrl+Y

**演示模式：**
1. 菜单 → 演示 → 开始演示
2. 点击按键触发逻辑
3. 观察数码管和LED变化
4. 按ESC退出演示模式

## 第三步：测试功能

### 测试1：编辑模式

## 常见问题

### Q1: 打开HTML后显示空白？

**A:** 检查浏览器控制台（F12）是否有错误。可能原因：
- 浏览器版本过旧，不支持ES6
- 文件路径不正确

### Q2: 按键点击没反应？

**A:** 确认是否在演示模式。编辑模式下按键只用于拖拽，不触发逻辑。

### Q3: 数码管一直显示"----"？

**A:** 
- 编辑模式下正常（不执行逻辑）
- 演示模式下应显示实际值，如未变化请检查控制台错误

### Q4: 如何加载参考图？

**A:** 菜单 → 视图 → 加载参考图，选择面板实拍PNG图片，会半透明显示在Canvas底层辅助定位。
