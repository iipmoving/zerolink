# 底图嵌入配置功能说明

## 🎯 功能概述

现在可以将底图**直接嵌入到配置JSON文件**中，下次加载配置时自动恢复底图和控件位置。

---

## 📦 技术实现

### 1. 保存配置时（导出）

**流程**：
```
用户点击"保存配置"
    ↓
调用 saveConfig()
    ↓
调用 exportBackgroundImage()
    ↓
将底图转换为Base64编码
    ↓
保存到JSON的background.data字段
    ↓
下载JSON文件（包含完整的底图数据）
```

**JSON结构**：
```json
{
  "version": "1.0",
  "panel_name": "default面板",
  "canvas_size": {
    "width": 800,
    "height": 600
  },
  "controls": [...],
  "background": {
    "data": "data:image/png;base64,iVBORw0KGgoAAAANS...",
    "scale": 1.0,
    "offsetX": 0,
    "offsetY": 0
  }
}
```

### 2. 加载配置时（导入）

**流程**：
```
用户选择JSON文件
    ↓
调用 loadConfigFromFile()
    ↓
检测background.data字段
    ↓
调用 importBackgroundImage()
    ↓
从Base64创建Image对象
    ↓
设置AppState.backgroundImage
    ↓
恢复底图缩放和偏移
    ↓
重新渲染Canvas（控件位置不变）
```

## 🔧 核心函数

### exportBackgroundImage()

**功能**：将底图转换为Base64编码

```javascript
function exportBackgroundImage() {
    return new Promise((resolve) => {
        if (!AppState.backgroundImage) {
            resolve(null);
            return;
        }
        
        // 创建临时Canvas
        const canvas = document.createElement('canvas');
        const ctx = canvas.getContext('2d');
        
        canvas.width = AppState.backgroundImage.width;
        canvas.height = AppState.backgroundImage.height;
        
        // 绘制图片
        ctx.drawImage(AppState.backgroundImage, 0, 0);
        
        // 转换为Base64
        const base64Data = canvas.toDataURL('image/png');
        
        resolve({
            data: base64Data,
            scale: AppState.backgroundScale || 1.0,
            offsetX: AppState.backgroundOffsetX || 0,
            offsetY: AppState.backgroundOffsetY || 0
        });
    });
}
```

### importBackgroundImage()

**功能**：从Base64恢复底图

```javascript
function importBackgroundImage(backgroundConfig) {
    return new Promise((resolve) => {
        if (!backgroundConfig || !backgroundConfig.data) {
            resolve(false);
            return;
        }
        
        const img = new Image();
        img.onload = () => {
            AppState.backgroundImage = img;
            AppState.backgroundScale = backgroundConfig.scale || 1.0;
            AppState.backgroundOffsetX = backgroundConfig.offsetX || 0;
            AppState.backgroundOffsetY = backgroundConfig.offsetY || 0;
            AppState.backgroundImagePath = 'embedded';
            
            log('底图已从配置中恢复', 'success');
            resolve(true);
        };
        
        img.onerror = () => {
            log('底图加载失败', 'error');
            resolve(false);
        };
        
        img.src = backgroundConfig.data;
    });
}
```

## 💡 使用场景

### 场景1：完整备份

**需求**：备份整个面板配置，包括底图和控件

## ⚠️ 注意事项

### 1. 文件大小

**Base64编码会增加约33%的文件大小**

示例：
- 原始图片：100KB
- Base64编码后：约133KB
- JSON文件：约135KB（含其他数据）

**建议**：
- 使用压缩后的PNG图片
- 避免使用过大的底图（建议<500KB）
- 如果底图很大，考虑使用外部引用

---

### 2. 浏览器兼容性

**支持的浏览器**：
- ✅ Chrome/Edge（推荐）
- ✅ Firefox
- ✅ Safari
- ⚠️ IE不支持（需要polyfill）

**Canvas.toDataURL支持**：
- PNG格式：所有现代浏览器
- JPEG格式：所有现代浏览器
- WebP格式：部分浏览器

---

### 3. 性能考虑

**加载大底图时**：
- Base64解码需要时间
- 图片渲染需要内存
- 建议底图尺寸不超过1920x1080

**优化建议**：
- 使用合适的图片尺寸
- 压缩图片质量
- 避免频繁保存/加载
