# AI配置使用指南

## 概述

系统支持两种JSON配置格式：
1. **简化格式**：AI生成友好，使用中文字段名
2. **内部格式**：系统标准格式，使用英文字段名

系统会**自动检测**并转换简化格式，无需手动处理。

---

## AI提示词模板

### 模板1：文字描述生成

```markdown
请根据以下面板规格生成JSON配置（简化格式）：

面板尺寸：约1000x400像素

控件列表：
1. 按键"开始/暂停"：位置(100, 280)，尺寸40x66，深色背景
2. 按键"加水"：位置(210, 280)，尺寸40x66
3. 按键"加时间"：位置(320, 280)，尺寸40x66
4. 按键"M1"：位置(660, 280)，尺寸40x66
5. 按键"M2"：位置(770, 280)，尺寸40x66
6. LED灯"电源灯"：位置(115, 190)，尺寸10x10
7. LED灯"M1灯"：位置(675, 190)，尺寸10x10
8. 数码管"四位显示"：位置(400, 285)，尺寸200x55，绿色文字

要求：
- 使用简化格式（type用中文：按键/LED灯/数码管）
- 坐标以左上角为原点
- 颜色使用十六进制格式
```

### 模板2：图片识别生成

```markdown
请分析这张面板图片，生成JSON配置（简化格式）：

[上传图片]

要求：
1. 识别所有按键、LED灯、数码管的位置和尺寸
2. 根据文字标签确定name字段
3. 估算合理的坐标和尺寸
4. 输出简化格式JSON

注意：
- type字段使用中文：按键、LED灯、数码管
- 按键名称映射：开始/暂停→KeyCode 13, M1→1, M2→2, 加水→11, 加时间→12
- LED名称映射：电源灯→bit 0, M1灯→bit 1, 加水灯→bit 11
```

## 使用步骤

### 方法1：菜单加载

1. AI生成JSON文件，保存为 `configs/xxx.json`
2. 打开应用，菜单 → 文件 → 加载示例配置
3. 系统自动检测格式并转换
4. 在编辑模式中微调位置

### 方法2：文件打开

1. AI生成JSON文件
2. 菜单 → 文件 → 打开配置
3. 选择JSON文件
4. 系统自动转换并加载

## 常见问题

### Q1: AI生成的坐标不准确怎么办？

**A:** 这正是设计的目的！AI负责生成80%的布局，剩余20%通过编辑器手动微调：
1. 加载AI生成的配置
2. 在编辑模式下拖拽控件到准确位置
3. 使用对齐工具快速调整
4. 上传参考图辅助定位

### Q2: 可以自定义映射规则吗？

**A:** 可以！编辑 `js/config_converter.js` 中的 `KEY_NAME_MAP` 和 `LED_NAME_MAP` 对象。

### Q3: 如何查看转换后的内部格式？

**A:** 加载配置后，菜单 → 文件 → 导出配置，会下载简化格式的JSON。如需内部格式，可在浏览器控制台输入：
```javascript
console.log(JSON.stringify(AppState.controls, null, 2));
```

### Q4: AI生成的配置缺少某些字段怎么办？

**A:** 转换器会使用默认值填充：
- 缺失 `bg_color` → 使用 `#e0e0e0`
- 缺失 `font_size` → 按键用12，数码管用32
- 缺失 `long_press` → 默认false
- 未识别的按键名称 → 按顺序分配KeyCode

## 最佳实践

### 1. AI生成前准备

- 准备清晰的面板图片或详细规格书
- 标注关键控件的名称和大致位置
- 提供颜色偏好（深色/浅色主题）

### 2. 生成后验证

- 检查控件数量是否正确
- 确认按键名称拼写（影响映射）
- 验证LED名称与位号的对应关系

### 3. 手动微调技巧

- **批量偏移**：选中多个控件，统一移动
- **对齐工具**：使用左/右/上/下/居中对齐
- **网格吸附**：开启网格显示，拖动时自动吸附
- **参考图**：上传实拍图，半透明显示辅助定位

### 4. 保存最终配置

- 微调完成后，菜单 → 文件 → 保存配置
- 导出的JSON可作为下次AI生成的参考
- 建议保留AI原始文件和微调后的文件两个版本

## 技术细节

### 转换流程

```
简化格式JSON
   ↓
detectConfigFormat() 检测格式
   ↓
convertConfig() 转换
   ├─ convertControl() 转换每个控件
   ├─ 映射type（中文→英文）
   ├─ 映射key_code（名称→数字）
   ├─ 映射led_bit（名称→位号）
   └─ 填充默认值
   ↓
validateConfig() 验证
   ↓
加载到AppState
   ↓
渲染Canvas
```

### 自动Canvas调整

系统会根据控件位置自动计算合适的Canvas大小：
```javascript
maxX = max(控件.x + 控件.width) + 50
maxY = max(控件.y + 控件.height) + 50
```

确保所有控件都能完整显示。
