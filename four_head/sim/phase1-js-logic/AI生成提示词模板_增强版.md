# EMC面板配置生成 - 增强版提示词模板

## 📋 使用说明

本提示词采用**两步验证流程**，确保生成的配置准确无误。

---

## 🎯 完整提示词（复制使用）

```
请帮我分析面板图片并生成EMC面板模拟器配置文件。

【第一步：输出检查报告】

请先仔细观察上传的面板图片，识别所有控件，然后生成一份《检查报告》，用表格形式汇总。

## 画布规格
- Canvas尺寸: 1024x600像素
- 有效布局区域: X(50-974), Y(50-550)
- 坐标系: 左上角(0,0)，向右X增加，向下Y增加

## 控件类型与默认规格

### 1. 按键 (Button)
- 默认尺寸: 宽40px, 高40px
- 颜色: bg_color="#2a2a2a", border_color="#555555", text_color="#cccccc"
- 命名: "开始 / 暂停", "加水", "加时间", "M1"-"M10", "电源"

### 2. LED灯 (LED Indicator)
- 默认尺寸: 宽10px, 高10px
- 颜色: bg_color="#333333", border_color="#555555", text_color="#cccccc"
- 命名: "XXX灯"，位于对应按键上方20-30px

### 3. 数码管 (Seven-Segment Display)
- 默认尺寸: 宽202px, 高55px（四位显示）
- 颜色: bg_color="#111111", border_color="#555555", text_color="#44ff44"
- 命名: "四位主显示"
- 位置: 居中放置 X=400-420, Y=270-300

|------|------|------------|------|----------|
| 1 | 开始 / 暂停灯 | (113, 190) | 10×10 | 开始 / 暂停 |
| ... | ... | ... | ... | ... |

### 3. 数码管列表（共 X 个）
| 序号 | 名称 | 坐标(X, Y) | 尺寸 | 默认显示 |
|------|------|------------|------|----------|
| 1 | 四位主显示 | (401, 282) | 202×55 | 8888 |
| ... | ... | ... | ... | ... |

## 汇总确认

## 💡 优化建议

### 提高生成质量的技巧

1. **明确控件数量**
   ```
   好：需要3个功能键
   差：需要一些功能键
   ```

2. **指定具体坐标或相对位置**
   ```
   好：从X=99开始，水平间隔100px
   差：均匀分布
   ```

3. **参考new.json的布局模式**
   ```
   可以参考项目中new.json文件的布局方式
   ```

4. **要求AI验证坐标范围**
   ```
   请确保所有坐标在有效区域内（X:50-974, Y:50-550）
   ```

5. **分步生成复杂布局**
   ```
   先生成按键布局，再生成LED，最后生成数码管
   ```

### 常见错误避免

❌ **错误1：坐标超出范围**
```json
{"x": 1050, "y": 650}  // 超出1024x600画布
```

✅ **正确：**
```json
{"x": 974, "y": 550}  // 在有效区域内
```

❌ **错误2：控件重叠**
```json
{"x": 100, "y": 276}, {"x": 110, "y": 276}  // 间距仅10px，太近
```

✅ **正确：**
```json
{"x": 100, "y": 276}, {"x": 220, "y": 276}  // 间距120px
```

❌ **错误3：LED位置不对齐**
```json
按键: {"x": 100, "width": 40},  // 中心X=120
LED: {"x": 100}  // 未对齐
```

✅ **正确：**
```json
按键: {"x": 100, "width": 40},  // 中心X=120
LED: {"x": 115}  // 中心X=120，对齐
```
