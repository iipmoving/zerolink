## 🎯 核心技术点

### 相对路径处理

#### 问题
HTML中使用相对路径引用资源：
```html
<script src="js/app.js"></script>
<link href="css/style.css">
```

如果从其他目录运行脚本，工作目录不正确会导致资源加载失败。

#### 解决方案
在脚本开头添加：
```batch
cd /d "%~dp0"
```

**作用**：
- `%~dp0` = 脚本文件的完整路径（驱动器+目录）
- `cd /d` = 切换到该目录（包括切换驱动器）
- 确保无论从哪里运行脚本，工作目录都是脚本所在文件夹

#### 示例

假设脚本位于：`D:\Projects\emc-web\phase1-js-logic-release\自动启动.bat`

```batch
:: 执行前
当前目录: C:\Users\Username\Desktop

:: 执行 cd /d "%~dp0"
当前目录: D:\Projects\emc-web\phase1-js-logic-release\

:: 现在可以正确加载
js/app.js → D:\Projects\...\js\app.js ✅
css/style.css → D:\Projects\...\css\style.css ✅
```

## 🎓 技术原理

### 批处理参数扩展

| 符号 | 含义 | 示例值 |
|------|------|--------|
| `%0` | 脚本完整路径 | `D:\test\start.bat` |
| `%~d0` | 驱动器 | `D:` |
| `%~p0` | 路径 | `\test\` |
| `%~dp0` | 驱动器+路径 | `D:\test\` |

### 目录切换命令

```batch
:: 只切换同驱动器目录
cd C:\Windows

:: 切换任意驱动器目录
cd /d D:\Projects

:: 切换到脚本所在目录
cd /d "%~dp0"
```
